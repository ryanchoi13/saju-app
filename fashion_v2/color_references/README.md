# 코디 색 참고 데이터

코디 배색의 근거로 쓸 수 있는 외부 자료를 **출처와 함께** 모아 두는 곳이다.
2026-10-28 코디 데이터 설계안의 원칙을 따른다: 전문가가 아는 것으로 추천하고, 근거가 있는 데이터만 쓴다.

- 여기 있는 파일은 아직 추천 엔진에 연결되지 않았다. 참고 데이터로만 보관한다.
- 원본 이미지·영상은 저장하지 않는다. 색 값(HEX), 역할, 면적 비율, 출처만 기록한다.
- `domain`이 `graphic_design`인 자료는 포스터·화면용 배색이다. 옷에 쓰기 전에 실착 근거로 검증한다.

## 공통 형식

| 키 | 뜻 |
| --- | --- |
| `source` | 출처(제목, 만든 사람, 수집한 사람·날짜, 주의 사항) |
| `domain` | `graphic_design` / `fashion` 등 자료가 원래 쓰인 분야 |
| `combinations[].colors[].role` | `base`(바탕, 가장 넓음) · `main`(중심) · `point`(강조, 가장 작음) |
| `combinations[].colors[].ratio` | 면적 비율(%), 한 조합의 합은 100 |
