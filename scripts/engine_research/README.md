# 엔진 연구 스크립트 (2026-11-05)

화면·서비스 코드가 아니라 **측정·검증용**. 저장소 루트에서 실행한다. 결과 파일은 `RESEARCH_OUT`(기본 /tmp)에 쓴다.

| 스크립트 | 하는 일 |
|---|---|
| strength_baseline.py `<정답 csv>` | 지금 엔진의 강약 판정을 정답 세트로 채점(간지 → 같은 기둥의 날짜를 찾아 엔진 실행). 1~2분 |
| strength_proto.py | 세력 저울 1차(돕는 힘 : 빼는 힘 비율) + 공용 함수(지장간 표, 정답 읽기) |
| strength_proto3.py | 세력 저울 3차(12운성 뿌리) — 80개 하나 빼기 교차검증. 수십 분 걸림 |
| natal_contradiction.py `[N]` | 무작위 N명의 원국 보완 1순위가 억부 방향과 어긋나는 비율 |
| measure_lucky.py `[명] [일]` | 가상 사용자 × 일수로 행운 색(같은 오행 두 색, 연속, 점유율) 측정 |
| impact_johu.py | 강약 보류자에게 궁통보감 조후용신을 쓸 때의 변화(보완 오행 변화, 점수 카드 과다와 겹침) |
| build_gungtong.py | `docs/engine/gungtong-johu.csv` 를 만든 스크립트. 원문 전사본(殆知閣 계열, udn DejaVu)은 저장소에 없어서 그대로는 다시 돌릴 수 없다 — 근거 기록용 |

규칙: 개인 생년월일(정오님 등)은 스크립트·결과에 넣지 않는다(헌장 작업 규칙 8). 재현이 필요하면 실행할 때만 인자로 넣는다.
