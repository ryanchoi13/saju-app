# 달하 코디 근거 데이터 · 검토 초안 0.1

2026-10-02 · 운영 추천에는 연결하지 않은 연구·검토본

## 만든 결과와 범위

기존 의류 팔레트의 141개 고유 HEX(와다 115 + 기본·조정 26), 기존 도안 49종을 고정 목록으로 정리했다. 원래 추천색의 뜻이나 오행은 바꾸지 않았다. 액세서리 금속색, 무늬·부분색, 실제 상품의 미세한 색 차이까지 모두 검증한 목록은 아니다.

한국 패션 매체·국내 상품 페이지 15건을 출처 목록에 등록했다. 그중 14건의 공개 확인 범위에서 28개 구성·관찰 기록을 만들었고, 본문 접근이 되지 않은 1건은 근거에서 제외했다. 기록에는 부분 조합과 상품의 색상 옵션도 포함된다. 28벌의 완성된 코디를 검증했다는 뜻이 아니다. 별도 수집기는 12건의 메타데이터를 갱신했고, 접근 제한 등을 발견한 3건을 자동 수집에서 제외했다.

33개 초기 점수 규칙, 12개 부분 조합 패턴, 오늘 사례와 대안 6개, 검토 이력을 연결했다. HTML에서 성별·연령·계절·TPO·아이템·색상 풀을 선택하면 점수와 이유를 비교할 수 있다. 검토 메모는 브라우저 내에 보관되며 JSON으로 내보낼 수 있다. 그 메모가 운영 점수에 자동 적용되지는 않는다.

## 이 구조를 택한 이유

- **관찰과 판단 분리:** 출처에 특정 코디가 있었다는 사실과, 달하에서 몇 점을 줄지는 다른 데이터다.
- **고정된 색상 ID:** 같은 이름의 다른 HEX를 혼동하지 않는다. 사진의 색은 가장 가까운 등록색으로 연결하되 `approximate_editorial_mapping`으로 표시한다. 실물 색 측정값이 아니다.
- **조건별 초안:** 공통 규칙과 구체적인 조건의 규칙을 분리한다. 더 구체적인 검토 규칙을 높은 우선순위로 두며, 같은 우선순위에서 점수가 충돌하면 미평가로 돌려 검토한다. 근거 수만으로 점수를 더하지 않는다.
- **기본형·실험형 ≠ 출처 신뢰도:** 해외 런웨이를 한국 일상 착장으로 계산하지 않는다. 같은 발행 그룹·원래 사진을 구분하며, 같은 사진을 재게시한 자료는 독립 근거로 세지 않는다.
- **미평가 유지:** 10대·50대 직접 사례, 일반인 대표성, 실제 보유율이 부족하다. 전체 경우를 임의의 3점으로 채우지 않는다. 연령 차이의 초기 규칙은 사용자 가설로 표시했다.
- **전체 코디 별도 검토:** 부분 조합이 각각 좋아도 전체 조화가 보장되지 않는다. 색수, 면적, 레이어, 소재, 실루엣, 신발, 실제 날씨를 종합하는 시각 검토가 남는다.

## 점수 해석

| 값 | 뜻 |
|---|---|
| 1 | 해당 조건에 맞지 않음 |
| 2 | 기본 추천에서는 후순위 |
| 3 | 조건부 후보 |
| 4 | 기본 추천의 우선 후보 |
| 5 | 반복 검수한 기준 사례 |
| null | 미평가 또는 충돌 |

초기 점수는 달하의 서열형 판단값이며 실측 착용률·미적 확률이 아니다. 이번 초안에는 5점이 없다. 점수의 근거는 기존 정책(`legacy_policy_editorial_seed`), 사례를 참고한 제안, 상품 존재를 참고한 제안, 사용자 피드백·가설로 구분했다. 초기 점수가 있다는 것과 외부 근거가 충분하다는 것은 다르다.

보편적인 성별·연령 금지 규칙을 만들지 않았다. 예컨대 남성 40·50대 가을 캐주얼의 핑크 블루종 2점은 이번 피드백을 반영한 기본 추천 초안이다. 다른 성별·계절로 자동 확장하지 않는다. 10대 여성 핑크 팬츠 3점, 50대 남성 2점의 차이는 사용자 예시를 기록한 미검증 가설이지 조사 통계가 아니다.

기존 날씨·TPO 판단은 우선 조건이다. 여기의 계절별 색 점수만 보고 여름 코트, 비 오는 날의 신발 등 물리적 적합성이 확인됐다고 판단하면 안 된다.

## 오늘 사례의 검증 결과

- **B01/B02:** 같은 배색을 기존 도안으로 재현. 낮은 아이템 현실성과 사용자 반려 기록이 함께 남아 `revise`로 분류된다. 추천색을 두 개 사용했다고 이를 상쇄하지 않는다.
- **B03:** 검정 블루종 + 핑크 긴팔 티 + 베이지 면바지 + 검정 운동화. 사용자의 제안을 구체화한 비교안. 핑크·베이지는 O03을 참고했지만 검정 겉옷을 더한 완성 착장은 새 제안이다.
- **B04:** 네이비 블루종 + 핑크 긴팔 티 + 베이지 면바지 + 네이비 운동화. 부분 근거 두 개를 연결했지만 전체 자동 승인은 하지 않는다.
- **B05:** 네이비 블루종 + 화이트 긴팔 티 + 베이지 면바지 + 화이트 운동화. 핑크를 팔레트에만 남기는 안이다.
- **B06:** 해외 방송의 핑크 셔츠·연청·브라운 로퍼 사례를 도안으로 옮긴 참고안. 원문의 여름·방송 맥락을 한국 40대 가을 일상으로 검증한 것은 아니다.

베이지 활용안은 원래 노랑을 그대로 사용한 것으로 계산하지 않는다. `wada-FBE6A0 → wardrobe-beige` 연결은 `owner_proposed_pending_review`로 두었다. 모든 노랑을 베이지로 바꾸는 규칙은 만들지 않았다. 기존 엔진의 톤 후보 250건도 후보 이력이며 미적 승인이 아니다.

HTML의 실제 사진 2장은 GQ Korea의 원문을 열어 확인한 참고 자료다. 색상 팔레트와 실물 사진은 조명·소재가 다르다. 해당 사진이 일상 보급률의 근거가 되는 것은 아니다. 사진 원문 링크와 확인 위치는 `sources.json`, `observations.json`에 있다.

## 자료 편향과 다음 검토

한국 매체의 셀럽·기획 화보가 중심이다. 국내 언론에 실린 해외 사례도 많다. 연령이 본문에 명시된 기록은 40대 해외 인물 1건이며 10대·50대 직접 표본은 없다. GQ·W·Allure는 같은 발행 그룹으로 묶어 서로 완전히 독립된 증거처럼 처리하지 않았다. 조회수·좋아요·상품 리뷰 수를 착용률 점수로 바꾸지 않았다.

다음에는 (1) B03~B05의 실제 조화, (2) 5단계 점수 기준, (3) 기본형·실험형 분류를 함께 검토한다. 이후 한국 일반인과 부족한 연령·계절·TPO를 보강하고, 고정 사례를 다시 검사한 버전부터 운영 적용을 검토한다. 새로운 커머스 기능이나 유료 AI 이미지 생성은 이번 범위에 추가하지 않았다.

## 월별 갱신 절차

새 URL을 출처 목록에 등록 → 공개 접근·중복·원출처 확인 → 관찰 기록 작성 → 색·아이템 매핑 → 점수 변경안과 이유 기록 → 기준 사례 재검토 → 검토된 버전 반영.

기본형에는 여러 시기와 독립된 사례의 뒷받침을 추가한다. 실험형에는 적용 조건과 재검토 시점을 남긴다. 단지 최신이라는 이유로 점수를 올리지 않는다. 기존 자료는 수정 이력과 함께 남기고, 원문이 사라지면 확인 불가 상태로 표시한다. 이번 작업에서 자동 실행 일정은 추가하지 않았다.

## 데이터 파일

- `colors.json`, `garments.json`: 고정 색상과 아이템.
- `sources.json`, `observations.json`: 출처와 구성 기록. 원문 전문은 보관하지 않음.
- `color_mappings.json`: 원래 추천색과 착장용 톤 후보. 승인 상태 분리.
- `rules.json`, `patterns.json`: 조건별 점수 초안과 부분 조합 근거.
- `benchmarks.json`, `review_events.json`: 고정 검토 사례와 피드백 이력.
- `source-refresh.json`: 공개 페이지 메타데이터 수집 결과. 수집 성공은 내용 승인과 다름.
- `dalha-fashion-evidence.sqlite`: 조건별 조회용 데이터베이스. `full_matrix`에서 미평가를 포함한 모든 등록 조합 조회 가능.

조건은 남·여 × 10~50대 5구간 × 4계절 × 3TPO = 120개다. 전체 등록 조합 829,080칸은 조회 범위이지 검증한 데이터 수가 아니다. 실제 초안 점수 수는 `build-report.json`의 `scored_draft_cells`에 기록된다.

```sql
SELECT g.name AS item, c.name AS color, c.hex, m.score, m.status
FROM full_matrix m
JOIN garments g ON g.id=m.garment_id
JOIN colors c ON c.id=m.color_id
WHERE m.context_id='male-forties-autumn-casual' AND g.name='블루종';
```

## 검증한 범위

- 핵심 동작 테스트 8개 통과: 미평가 처리, 조건별 규칙, 점수 충돌, 기존 반려 사례, 부분 조합과 전체 판단 분리.
- SQLite 외래 키 및 무결성 검사 통과.
- 화면의 점수 계산과 데이터베이스 16,283개 조회 결과 일치(초안 16,253개와 미평가 30개).
- 데스크톱 1280px·모바일 390px에서 화면과 가로 넘침 확인. 필터·검색·검토 메모·JSON 내보내기 확인. 브라우저 스크립트 오류 없음.

이 검증은 데이터와 도구가 설계대로 동작하는지에 관한 것이다. 점수의 사회적 대표성이나 코디의 미적 완성도를 검증한 결과는 아니다.
