# 강약 판정 정답 원국 세트 (2026-11-05 수집)

결정 문서: 프로젝트 `claude/decisions-2026-11-05-strength.md`, 엔진 헌장 `claude/part-engine.md`(알려진 문제 0).

## 파일
| 파일 | 개수 | 주 출처 |

| set1.csv | 40 | 『적천수천미』 30(전사본 blog.udn.com/DejaVu), KCI 논문 7, 명리가 1, 커뮤니티 1 |
| set2.csv | 62 | 『자평진전평주』 28, 『천리명고』 12, 『삼명통회』 9(사고전서 문연각본 대조), 『연해자평』 8, 『적천수천미』 5 |

열: id, year, month, day, hour(간지), verdict(신강/신약/극신강/극신약/경계/판정갈림 등), verdict_original(원문 표현 요약), basis(판정 근거, set2는 `[중간:…]` 표시), yongshin, special_structure(종격·종왕·화격·태쇠-반억부 등 — 억부 채점에서 뺌), source, reliability(높음/중간/낮음), conflict_note

## 채점 규칙
- 일반 억부 채점 = verdict가 신강·극신강·신약·극신약이고 special_structure가 빈 행(현재 80개)
- 간지만 있는 명조는 같은 네 기둥이 나오는 양력 날짜·시각을 찾아 엔진에 넣는다(`scripts/engine_research/strength_baseline.py`)
