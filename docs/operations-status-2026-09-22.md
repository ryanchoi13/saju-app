## 이번 변경 — 최종 승인 후 PR 배포 진행

### 가입 안내

- 최초 한 번 기본 정보를 직접 입력하고 다음 로그인부터 저장된 정보를 사용한다고 명시.
- 정보 불러오기 버튼은 기본 숨김. 실제 Kakao 응답에 미입력 항목의 `*_needs_agreement === true`가 있을 때만 표시.
- 저장된 ID로 재접속했으나 프로필이 미완료인 경우, 추가 동의 가능 여부를 추정하지 않고 직접 입력 안내.
- 향후 권한 승인 후 사용할 검증된 자동 입력/추가 동의 처리 자체는 보존.
- 닉네임을 실명으로 대체하거나 생일·성별 기본값을 만들어 채우지 않음.

### 기존 실패 테스트

- 대상: `test_ranked_menu_explorer.py::MenuStoreTests::test_api_profile_binding_and_service_integration`
- 재현: 구 `menu_store`에서 만든 토큰을 현재 `meal_set_store` 기반 API에 전달하여 403 발생. 날짜 패치 대상도 구 저장소였음.
- 수정: 실제 분석 서비스에서 생성한 현재 식단 토큰을 사용하고, API 날짜를 해당 응답 날짜에 맞춤. 아침·점심·저녁 3개, 추천 상한 3, 추천 이력 증가를 검사.
- 미등록 사용자 401 및 구 토큰 403 검사를 보존/추가. 운영 서버의 토큰 검증은 완화하지 않음.
- 과거 랭킹·저장소 단위 테스트는 그대로 유지.

### 랜딩 1차 시안

- 협의 후 확정한 핵심 문구: “운을 알고, 나를 알면 / 살아가는 일이 조금 더 수월해집니다.”
- 윗문구: “내 생활의 작은 지침서, 달하”. 전체 랜딩 최종 승인 및 배포 요청 확인.
- 구성: 서비스 가치 소개 → 시작 버튼 및 최초 입력 안내 → 소개용 결과 카드 → 운세/코디/식단 기능 → 시작 링크.
- 아이보리·그린 계열. PC 2열/모바일 1열. 신규 방문 화면의 충전 버튼과 중복 푸터는 숨김.
- 3초 가입과 가입 보상을 첫 화면 중심 문구에서 제거. 보상 지급 로직은 변경하지 않음.
- 소개용 문구·색상·그림임을 명시. 효능·미래 결과를 보장하는 문구 없음.
- 실제 로그인 함수와 로그인 후 기존 앱 화면 연결 유지. 분석·추천 알고리즘 변경 없음.
- 기능 소개: “오늘, 뭐 입을까? 뭐 먹을까? 어떤 하루를 보낼까?”; 코디 → 식단 → 운세 순서.
- 음식 소개는 아침·점심·저녁, 일반식·다이어트, 음양오행 관점의 조합 및 끼니별 칼로리로 설명. 영양 균형을 보장하지 않음.
- 랜딩 푸터는 정읍사에서 따온 브랜드 의미와 사주 해석 방식 소개로 변경. 건강·영양 안내는 식단 화면의 펼쳐보기로 이동.
- `scripts/export_landing_preview.cjs`로 만드는 확인용 HTML은 실계정 로그인/저장 없는 독립 시안.
