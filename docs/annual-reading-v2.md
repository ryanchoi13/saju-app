# 올해·월별 풀이 — conversational v2

## 범위

- 사용자가 2026-09-23 확정한 말투를 올해운세 상품에 적용한다. 일간·평생·테마운, 음식·코디 계산은 변경하지 않는다.
- 사람에게 이야기하듯 편하게 읽히되 조언은 구체적으로 쓴다. 격려와 주의점에 강약을 주고, 말끝만 ‘요’로 치환하지 않는다. 독자 호칭은 이름으로 통일한다.
- 총운 → 직업·사업 / 재물 / 애정 / 대인관계·가족 / 건강 / 학업·자기계발 → 12개월 총운과 짧은 여섯 분야로 구성한다.
- 가상 원고의 지우·하린·도윤이나 그 성향을 실제 사용자에게 대입하지 않는다. 이름·성별·월 번호로 문장을 무작위 배정하지 않는다.

## 근거와 한계

기존 `select_overall_domains`의 기간 격리, 순위, 조건부 관계 평가를 그대로 사용한다. 별도 `annual_editorial`은 십성·분야·관계 모드에 따른 편집 원고이며 새로운 길흉 점수나 사건 예측 모델이 아니다. 주요 주제와 동률은 유지하고, 기본 사주와 올해 주제의 연결을 설명한다.

여섯 분야를 읽기 편하게 제공하되, 해당 분야의 계산 근거가 없으면 `general_guidance` / ‘생활 조언’으로 표시한다. 근거가 없다는 이유로 ‘무난한 운’이라고 단정하지 않는다. 같은 관계가 여러 분야를 뒷받침해도 근거를 합산하거나 독립된 행운으로 세지 않는다. 월별은 해당 월까지의 계산으로 생성하며 일간 문구를 기간만 바꿔 재사용하지 않는다.

연간 대표값은 7월 1일, 월별은 15일(출생월 예외는 출생일)이다. 월초가 운의 전환일이라는 뜻이나 사건 발생 날짜로 안내하지 않는다. 정확한 절기 전후의 구간별 분석과 별도 전환점 장은 이번 범위가 아니다. 결과를 보장하거나 성격·직업·관계 상태를 사실처럼 꾸며내지 않는다.

## 기존 구매분

- 신규 구매는 `annual-conversation-v2`와 구매 연도를 저장한다. 서버 가격 300 복채와 기존 구매 멱등성은 유지한다.
- 기존 구매분은 명시적인 무료 업데이트 버튼으로 같은 구매 연도의 풀이를 현재 저장한 사주 정보로 재생성한다. 자동으로 원문을 덮어쓰거나 추가 차감하지 않는다.
- 이전 원문은 `previous_versions`에 보관하고 읽기 화면에서 버전을 선택할 수 있다. 최초 구매일, 다른 리포트, 지갑 잔액은 유지한다.
- 연도를 확인할 수 없으면 현재 연도로 추측하지 않고 중단한다. 갱신 실패 시 원문과 잔액을 유지한다. 동시 갱신은 지갑 행 잠금과 원본 비교를 통해 이력을 중복 저장하지 않는다.
- 계정 소유권, HttpOnly 세션, CSRF 보호는 기존 `/api/reports/` 경계를 그대로 따른다.
