# 코디 지식서 목차

전문가 교과 과정을 바탕으로 짠 목차다. 위에서부터 차례로 공부한다. 공부하면서 빠진 주제가 보이면 목차를 고친다.

목차의 근거
- 컬러리스트 과정: 색채 표준과 삼속성 → 배색 기법 → 형용사 이미지 배색 → 색채 계획 (교재 『COLORIST』, 한국색채학회, 2012) — [강의계획서](https://www.kocw.net:444/home/common/contents/syllabus/1288483_20180713154329548.pdf)
- 패션디자인·코디네이션 강의: 디자인 요소(선·실루엣·색채·소재) → 디자인 원리(비례·리듬·균형·강조·조화·통일) → 패션 이미지 → 패션 색채 배색 기법·유행색 분석 → 스타일 기획 (교재 『패션과 뷰티디자인을 위한 토털 코디네이션』, 광문각, 2012) — [목원대 강의계획서](https://www.kocw.net:444/home/common/contents/syllabus/1181147_20161219131644794.pdf)
