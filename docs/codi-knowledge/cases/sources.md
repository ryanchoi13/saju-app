# 자료원 목록

처음 작성: 2026-11-07 01:47 KST 실행(자료원 조사). 약관은 **직접 연 것만** "확인"으로 적는다.

## 0. 먼저 알아야 할 것: 이번 실행 환경의 접근 제한 (2026-11-07 확인)

- 클라우드 브라우저(Playwright)와 `curl`로 패션 사이트를 열려고 하면 **모두 연결 거부**됐다(에이전트 프록시가 막음).
  시험한 곳: musinsa.com, 29cm.co.kr, vogue.co.kr, vogue.com, gq.com, wear.jp, uniqlo.com, cos.com, hypebeast.com, fashionsnap.com, lfmall.co.kr, ssfshop.com, wconcept.co.kr, google.com, wikimedia.
- 그래서 **사진을 스크린샷으로 보는 방식이 지금은 안 된다.** 글로 읽는 도구(WebFetch)만 된다. 이 도구는 검색 결과에 나온 주소만 열 수 있고, 사진은 보지 못한다.
- 글만으로는 착장 카드를 만들 수 없다. 룩북 페이지를 글로 읽으면 **상품 목록**(이름·색)만 나오고 "어떤 옷을 같이 입혔는지"는 나오지 않는다(라코스테 KR 2025 겨울 룩북으로 확인). 상품 목록으로 조합을 만들어 내면 지어낸 기록이 된다.
- 풀려면: claude.ai 설정 → Capabilities(기능)의 허용 도메인에 아래 "쓸 수 있음" 사이트를 넣어야 한다(정오님 결정 필요). PR 본문에 적었다.
