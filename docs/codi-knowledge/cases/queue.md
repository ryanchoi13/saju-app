# 공부할 칸 (queue)

처음 작성: 2026-11-07. 칸 하나 = 나라 × 집단 × 스타일 × 시즌, 착장 20~25개.
- **시즌 표기(2026-11-08 리뷰 반영)**: 칸 이름의 `FW`·`SS`는 계절 묶음이다. 기준 범위는 최근 2년(FW = FW25·FW26, SS = SS25·SS26). **실제로 본 시즌은 상태 칸 앞의 `[수집 …]`과 각 파일 머리에 적는다.** 파일 이름도 `-fw25`·`-ss26`에서 `-fw`·`-ss`로 바꿨다.

상태는 `대기` → `진행 중(YYYY-MM-DD HH:MM KST)` → `완료(YYYY-MM-DD)`. 시작할 때 바로 `진행 중`을 적어 커밋·push 한다.
`진행 중`이 3시간 넘게 그대로면 버려진 것으로 보고 이어받는다.

## 일정 계산 (2026-11-07 01:47 실행 기준)

- 칸 수: 1단계 12 · 2단계 36 · 3단계 48 = **96칸**.
- 실행: 하루 3회(01:47·03:23·05:11), 회당 2칸 = 하루 6칸.
- 남은 실행: 11/7 2회(이번 실행은 자료원 조사) + 11/8~11/27 20일 × 3회 = **62회 = 124칸 분량**. 96칸보다 많다.
- 단계별: 1단계 12칸 = 6회 → 11/7 03:23부터 하면 **11/9 01:47에 끝**(목표 11/9 ✅).
  2단계 36칸 = 18회 → **11/15 01:47에 끝**(목표 11/20 ✅). 3단계 48칸 = 24회 → **11/23 01:47에 끝**(목표 11/27 ✅). 여유 14회.
- 그래서 스타일 수는 줄이지 않았다(집단마다 6개).
- **단, 위 계산은 사진을 볼 수 있다는 전제다.** 2026-11-07 현재 클라우드 브라우저가 패션 사이트에 접속하지 못한다(sources.md 0절). 접근이 안 풀리면 칸 공부를 시작할 수 없다.

## 접근이 막혀 있을 때 실행이 할 일

- **`부분` 칸 규칙(2026-11-07 추가)**: 출처가 1곳만 열려 착장 20개·브랜드 2곳을 못 채우면 `부분`으로 둔다. 다음 실행은 `부분` 칸을 건너뛰고 다음 `대기` 칸을 하되, 새로 열린 출처가 `부분` 칸에 맞으면 먼저 보강한다. 열린 출처가 어떤 칸에도 안 맞으면 아래 대체 작업을 한다.

1. 먼저 브랜드 룩북 한 곳을 열어 본다(접근 시험). 열리면 평소대로 칸을 한다.
2. 안 열리면 칸을 `진행 중`으로 바꾸지 않는다. 대신 아래 중 하나를 하고 PR 본문에 "접근 막힘"을 적는다.
   - brands.md "근거 없음" 칸 보강(공개 순위·판매 보도 찾기)
   - sources.md 일본·미국·유럽 약관 확인
   - 지어낸 기록을 만들지 않는다. 상품 목록만으로 착장 카드를 만들지 않는다.
