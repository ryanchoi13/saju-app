# 한국 · 40대 남성 · 미니멀 · SS (사례 카드)

- **칸 시즌 표기**: 칸 이름의 "SS"는 계절 묶음(봄·여름)이고, 기준 범위는 최근 2년(SS25·SS26)이다. **실제 수집 시즌: SS26 25착장·SS25 10착장**(시스템옴므 No.1 14·No.2 11, 타임옴므 SS25 No.2 10 — 2026-11-12 보강).
- 칸: queue #54. 처음 기록: 2026-11-11 05:12 KST 실행. **2026-11-12 01:47 KST 보강**: 타임옴므(한섬) 2025 S/S No.2 10착장(#26~#35)을 더해 **브랜드 2곳·기업집단 1곳**(둘 다 한섬)이 됐다 → `완료`. 같은 회사라 README 기준으로 "브랜드 2곳·기업집단 1곳에서 반복"으로 쓴다(칸 #6 FW와 같은 두 브랜드).
- 출처 **1곳**: **시스템옴므**(한섬) 2026 S/S No.1(초봄)·No.2(여름) 룩북. 같은 브랜드 룩북 여러 권은 README 판정 기준대로 **출처 1곳**이다. 그래서 이 칸은 **`부분`** 으로 두고, 노트의 공식은 모두 **"1곳 관찰"** 로 쓴다.
- 두 번째 출처를 찾은 과정: FW 칸(#6)의 다른 출처였던 **타임옴므**는 SS26 No.1·No.2를 댄디 SS 칸(#50)에 이미 썼다. 타임옴므 2025 S/S No.3·No.4를 열어 봤지만 No.3는 체크 셔츠·데님 위주(캐주얼 베이직 쪽), No.4는 원경·분위기 컷이 대부분이라 미니멀 착장 카드로 쓸 수 없었다. brands.md 미니멀 후보(띠어리·포터리·COS 등)는 여전히 못 연다(sources.md 0절).
- 대상: 시스템옴므는 이 페이지에서 **타깃 연령을 밝히지 않는다**(→ "미표기"). FW 칸과 같이 **40대 근거 없음**(brands.md 후보 밖). 사진을 보고 모델 나이를 짐작하지 않았다.
- 시즌: SS26 No.1(2026-02-05 공개, 베이지 벽 스튜디오, 가죽·코트가 있는 초봄), SS26 No.2(2026-04-10 공개, 흰 벽·주름 커튼 스튜디오, 반팔·쇼츠 여름).
- 사진은 공식 페이지를 클라우드 브라우저로 열어 스크래치 폴더에서만 봤다. 색은 **화면 기준 근사값**이다. No.1은 필름 느낌의 따뜻한 보정이 있다.
- **스타일 판단**: 시스템옴므를 미니멀로 둔 것은 FW 칸과 같다(크부장 판단). SS26 No.2는 줄무늬 니트·쇼츠가 많아 캐주얼 베이직 쪽 착장도 섞여 있다 — 카드의 "스타일" 칸에 보조 스타일로 적었다.
- 뺀 것: No.1 04(누운 반사 연출, 가죽 블루종 근접 — #1과 같은 옷)·01(로고). No.2 13(그림자 사물 컷)·26(하늘색 결 반팔 셔츠 + 흰 티 + 베이지 바지 — 상반신·신발 안 보임). No.3(2026-05-19, 사진 30장)은 이번에 칸이 차서 보지 않았다.
- 시험용: 5번째 카드마다(#5·#10·#15·#20·#25). 노트 작성에는 쓰지 않았다.
