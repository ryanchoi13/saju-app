### 집계 (시험용 4장 제외, 18장)

- **크부장 판정 미니멀(근접 포함)**: 6장(#3·#4·#7·#8·#13·#14). 클래식 1(#1), 캐주얼 11(#2·#6·#9·#11·#12·#16·#17·#18·#19·#21·#22). "미니멀" 태그 안 실제 미니멀은 1/3 — R1(여성 9/24)과 비슷하다. 남성 회원은 "미니멀"을 **무늬 없는 기본 캐주얼**에도 붙인다.
- **공식 1(짙은 무채색 한 톤)**: 4장(#7·#8·#13·#14, 올블랙 3). 위만 블랙·아래 데님 1장(#3). → 미니멀 판정 착장(6장) 안에서는 **4/6으로 잘 맞는다.** 전체로는 4/18.
- **공식 2(겉보다 밝은 이너 한 점)**: 5장(#1 셔츠 칼라·#2 흰 티·#7 회색 니트·#11 흰 탱크·#13 토프 티). → **보임.** 짧은 블랙 아우터(트러커·블루종·레더) 안에 흰·회색 이너가 가장 흔한 형태다.
- **공식 3(셋업·톤온톤)**: 같은 원단 셋업 **0장.** 같은 색 위아래는 올블랙 3장(#8·#14 + #7)뿐. → **실착에서 셋업은 안 보인다.**
- **공식 4(갈색 아우터 + 짙은 안·아래)**: **0장.** 갈색은 아우터가 아니라 **바지**(#1 브라운 치노·#22 브라운 와이드·#17 회갈)와 **작은 점**(#2 첼시부츠·#4 가죽 칼라·#13 벨트)으로 나왔다. → 룩북과 **자리가 다르다**: 실착은 "짙은 위 + 갈색 바지".
- **공식 5(스트레이트~와이드, 발등~바닥)**: **18/18.** 슬림 0장. 바닥에 닿거나 쌓이는 **와이드**가 대부분이고, 커브드·카펜터·워크 와이드도 4장(#6·#14·#16·#21). → **아주 잘 맞는다**(룩북보다 더 넓다).
- **데님 비중**: 9/18(#2·#3·#4·#9·#11·#13·#16·#18·#21). 연청·중청 6, 인디고 생지 2, 블랙 워싱 1. 룩북(블랙 데님 중심)보다 **밝은 데님**이 많다.
- **신발(18장)**: 블랙 가죽(로퍼·더비·부츠·클로그) **10장**(#1·#3·#4·#7·#9·#12·#13·#14·#17·#21) — 시스템옴므 룩북(블랙 가죽 12/12)과 같은 방향. 운동화 5장(#6·#8·#16·#18·#22), 갈색·탠 부츠 3장(#2·#11·#19). 흰 가죽 스니커즈(타임옴므 룩북 4/4)는 0장.
