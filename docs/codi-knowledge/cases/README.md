# 코디 사례 공부 (실제 착장 편)

2026-11-06 정오님 결정으로 코디 공부를 **실제 착장 사례 중심**으로 바꿨다.
01~17장(`../01-…` ~ `../17-…`)은 **기초 이론편**으로 남기고, 사례에서 나온 공식을 검사할 때만 쓴다.
계획 원문: 프로젝트 문서 `claude/codi-study-method-v2-2026-11-06.md`.

- 목표: 취향이 아니라 **상황에 맞는 코디를 전문가처럼 정확하게** 추천하는 것. 전문가는 튀게 입지 않는다.
- 마감: 1단계 11/9 · 2단계 11/20 · 3단계 11/27 · 시험 11/28~30 (진행은 [queue.md](queue.md)).

## 원칙

1. **범위**: 한국·일본·미국·유럽. **중국 자료는 쓰지 않는다.** 기본 시기는 최근 2년(2025~2026 시즌). 그 이전 자료는 클래식 공식 확인용으로만 쓰고 연도를 적는다.
2. **집단**: 20대 여성 · 40대 남성. 실제로 없는 조합은 칸으로 만들지 않는다(예: 40대 남성 큐트).
3. **자료원 순서**: ① 브랜드 공식 룩북·코디 페이지 ② 패션지 스트리트 스냅·스타일링 기사 ③ 로그인 없이 공개되고 약관상 열람이 허용된 코디 플랫폼 ④ 시즌 트렌드 리포트.
4. **쓰지 않는 것**: 인스타그램, 핀터레스트, 로그인이 필요한 곳, 약관이 금지하는 곳, **약관을 직접 열어 보지 못한 플랫폼**(확인 전에는 쓰지 않음).
5. **크롤링하지 않는다.** 한 출처에서 한 번 실행에 30착장 안팎만 본다.
6. **이미지**: 공개 페이지를 클라우드 브라우저로 열어 스크린샷을 찍고 직접 보고 기록한다. 스크린샷은 스크래치 폴더에만 두고 저장소에는 **링크와 기록만** 남긴다. 색은 **화면 기준 근사값**이다.
7. **나이**: 사진을 보고 모델 나이를 짐작하지 않는다. 연령대는 **브랜드·매체가 밝힌 타깃**으로만 쓴다. 밝힌 것이 없으면 "타깃 미표기"로 쓴다.
8. **톤 문구**: 나이가 아니라 에너지로 쓴다. "젊어 보인다"는 쓰지 않는다.
9. **지어내지 않는다.** 사진을 보지 못한 착장은 카드로 만들지 않는다. 상품 목록만 있는 페이지(룩 단위가 아닌 것)로 착장 조합을 만들어 내지 않는다.
10. 정오님에게 자료를 골라 달라고 요청하지 않는다. 정오님이 자발적으로 보낸 자료는 같이 분석한다.

## 사례 카드 형식 (계획 문서 3절)

카드 하나 = 착장(룩) 하나 = 표 한 줄.

| 칸 | 적는 것 | 예 |
| --- | --- | --- |
| # | 파일 안 순번 | 1 |
| 출처 | 브랜드/매체 · 나라 · 링크 | 라코스테 KR 룩북 · [링크] |
| 시즌 | 시즌·연도 | FW25 |
| 대상 | 성별 · 브랜드가 밝힌 타깃 연령(없으면 "미표기") | 여 · 미표기 |
| 스타일 | 분류표 이름(+보조 하나) | 클래식(+캐주얼 베이직) |
| 상황·계절 | 출근(정장/비즈니스 캐주얼/자율)·데이트·주말 볼일·하객·여행 등 / 계절·기온대 | 주말 볼일 / 초겨울 |
| 아우터 · 상의 · 이너 · 하의 · 신발 · 가방 · 소품 | 자리마다 종류·핏(슬림/레귤러/오버)·길이·소재 | 하프 코트(레귤러·엉덩이 아래·울) |
| 색 | 자리별 색(화면 근사값), 바탕/중심/포인트 역할, 대략 면적(%) | 아우터 카멜(바탕 45%) … |
| 공식 | 레이어링, 넣어 입기, 포인트 위치, 색 수 | 니트 위 코트, 앞만 넣기, 포인트 머플러, 3색 |
| 시험용 | `시험용` 또는 빈칸 | 시험용 |

## 판정 기준

- 사례에서 나온 공식에는 **근거 카드 수**와 **"서로 다른 브랜드·매체 N곳에서 반복"**을 같이 적는다.
- 출처가 1곳뿐이면 **"1곳 관찰"**로 쓴다. 공식으로 올리지 않고 "관찰"로 둔다.
- 같은 브랜드의 룩북 여러 장은 출처 1곳이다. 같은 회사의 다른 브랜드(예: 삼성물산의 갤럭시와 빈폴)는 다른 출처로 세되, 노트에 같은 회사임을 적는다.
- 기초 이론편(01~17장)과 부딪히면 노트에 그대로 적는다. 이론을 사례에 억지로 맞추지 않는다.
- 관찰 결과와 크부장 판단(예: 행운 색이 들어갈 자리)은 나눠 쓰고, 판단에는 "(크부장 판단)"을 붙인다.

## 시험용 떼어 두기

- 한 칸 파일 안에서 **5번째, 10번째, 15번째 … 카드**(5의 배수 번호)에 `시험용`을 적는다(약 20%).
- 시험용 카드는 **스타일 노트를 쓸 때 보지 않는다.** 공식의 근거 수를 셀 때도 빼고 센다.
- 11/28~30 시험에서 같은 조건(상황·집단·스타일)으로 노트 공식만으로 착장을 만들고, 시험용 카드와 아이템 구성·핏·색 역할이 얼마나 맞는지 잰다.

## 스타일 노트 형식

`notes/<스타일>.md`: 정의 · 대표 아이템 · 핏 · 색 팔레트 · **기본 공식 3~5개**(근거 카드 수, 출처 N곳) · 나라별 차이 · 연령 변주 · 2025~26 트렌드 · 반례 · 기초 이론편과 부딪히는 점 · 행운 색이 들어갈 자리(크부장 판단) · 아직 모르는 것.

## 하지 않는 것

- 코드(main.py, fashion_v2, index.html 등)를 건드리지 않는다. 추천 엔진에 연결하지 않는다(화면에는 오늘의 행운 색 두 개만).
- merge하지 않는다. 새벽 알림을 보내지 않는다.
