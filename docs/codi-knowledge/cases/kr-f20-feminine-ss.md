# 한국 · 20대 여성 · 페미닌 · SS (사례 카드)

- **칸 시즌 표기**: 칸 이름의 "SS"는 계절 묶음(봄·여름)이고, 기준 범위는 최근 2년(SS25·SS26)이다. **실제 수집 시즌: SS26 25착장**(마인 13·오즈세컨 12).
- 칸: queue #53. 처음 기록: 2026-11-11 05:12 KST 실행.
- 출처 2곳: **마인**(한섬) 2026 S/S No.9·No.10 룩북, **오즈세컨**(O'2nd, 한섬) 2026 S/S No.5·No.6 룩북. FW 칸(#5)과 같은 두 브랜드다. **둘 다 한섬**이라 회사는 하나다(README 판정 기준대로 출처는 2곳으로 세되 노트에 적는다).
- 대상: 두 브랜드 모두 이 페이지에서 **타깃 연령을 밝히지 않는다**(→ "미표기"). 마인은 20대보다 위 연령대 쪽이라는 FW 칸의 크부장 판단(근거 문서 없음)이 그대로 남는다. 사진을 보고 모델 나이를 짐작하지 않았다.
- 시즌: 마인 SS26 No.9(2026-04-27 공개)·No.10(2026-05-12 공개), 둘 다 스튜디오 촬영. 오즈세컨 SS26 No.5(2026-05-11, 야외 숲·꽃밭)·No.6(2026-05-13, 실내 클래식 방).
- 사진은 공식 페이지를 클라우드 브라우저로 열어 스크래치 폴더에서만 봤다. 색은 **화면 기준 근사값**이다. 오즈세컨 No.5는 강한 햇빛·초록 반사로 색이 진하게 보인다.
- **연출 주의**: 오즈세컨 두 권은 맨발·누운 자세·소품(피자 상자·케이크) 연출이 강한 화보다. 옷 조합만 적었고, 맨발 컷은 신발을 "안 보임(맨발)"으로 적었다.
- 한 룩이 여러 장에 나뉜 경우 합쳐 한 카드로 썼다. 안 보인 자리는 "안 보임".
- 뺀 것: 마인 No.10 14·15(샴브레이 셔츠 + 같은 원단 쇼츠 — 신발이 안 보이고 캐주얼 쪽), 16·17(시어 체크 블라우스 + 데님 스커트 — 근접 컷만), 사물 컷(04·18·21·22). 마인 No.9 05·06(카멜 리넨 재킷 + 줄무늬 티 + 회색 데님 — 캐주얼 쪽), 10~12(줄무늬 니트 카디건 + 쇼츠 — 프레피 쪽), 18~20(글렌체크 노칼라 재킷 + 와이드 데님 — 클래식 쪽, #57 후보), 23~25·30~32·39·40은 칸이 25착장을 넘어 넣지 않았다(아래 "남긴 자료"), 사물 컷(09·29). 오즈세컨 No.6 11·12(튤 러플 블라우스 — 근접 위주)·15·16(그래픽 링거 티 + 주름 미니 — 캐주얼 쪽).
- 시험용: 5번째 카드마다(#5·#10·#15·#20·#25). 노트 작성에는 쓰지 않았다.
