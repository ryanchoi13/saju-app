# 한국 · 40대 남성 · 클래식·트래드 · SS (사례 카드)

- **칸 시즌 표기**: 칸 이름의 "SS"는 계절 묶음(봄·여름)이고, 기준 범위는 최근 2년(SS25·SS26)이다. **실제 수집 시즌: SS25 10착장**(갤럭시 10).
- 칸: queue #52. 처음 기록: 2026-11-11 03:23 KST 실행. 상태: **`부분`(출처 1곳·10착장)**.
- 출처 1곳: **갤럭시**(삼성물산 패션) SSF샵 브랜드관 LOOKBOOK "25 S/S" 탭(리스본 거리 촬영). brands.md 클래식 후보 중 열리는 곳은 갤럭시뿐이다. 갤럭시 "26 S/S" 탭은 댄디 SS 칸(#50)에 이미 써서 다시 쓰지 않았다.
- **20착장·2곳을 못 채운 이유(이번 실행에서 시도한 것)**:
  - 빈폴 맨 SS 기획전 2곳: "키워드로 답하는 여름 착장의 정답"(special 119597)은 상품 착용 컷(잘린 사진)과 캐주얼(바람막이·쇼츠) 위주라 클래식 착장 카드로 못 씀. "한여름의 새로운 옷"(special 119808)은 페이지에 **"생성형AI를 활용한 이미지가 포함"** 표시가 있어 뺐다(README 9번 취지).
  - 타임옴므(한섬) 2025 S/S No.3·No.4: 줄무늬·체크 셔츠·니트 셔츠·쇼츠 중심의 캐주얼이라 클래식이 아님.
  - 더 캐시미어(한섬) SS26 No.4·No.6: 남성 컷이 니트 캐주얼 몇 장뿐.
  - 갤럭시 브랜드관 기획전은 예복(BRIGHT DAY, BEST SUIT)·시즌오프 할인 사진이라 쓰지 않음(FW 칸과 같은 판단).
  - 닥스·헤지스(LF몰)·폴로·브룩스브라더스는 여전히 안 열림(sources.md 0절).
- 대상: 갤럭시는 이 페이지에서 **타깃 연령을 밝히지 않는다**(→ "미표기"). 칸 배정은 brands.md 기준이다. 사진을 보고 모델 나이를 짐작하지 않았다.
- 사진은 공식 페이지를 클라우드 브라우저로 열어 스크래치 폴더에서만 봤다. 색은 **화면 기준 근사값**이다. 강한 햇빛·필름 보정이 있어 베이지·아이보리가 따뜻하게 보일 수 있다. 사진 아래쪽에 "생성형 AI" 표시는 없었다(1·5·8번 확인).
- 10컷이 모두 다른 착장이라 컷 하나 = 카드 하나. 대부분 상반신~허벅지 컷이라 **신발은 2장(#1·#2)만 보인다.** 안 보인 자리는 "안 보임".
- 시험용: 5번째 카드마다(#5·#10). 노트 작성에는 쓰지 않았다.
