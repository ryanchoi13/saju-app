### 집계 (시험용 4장 제외, 17장)

- **크부장 판정 클래식(프레피·근접 포함)**: 11장(#1·#2·#4·#6·#7·#8·#12·#13·#17·#18·#19). 캐주얼 5(#3·#9·#11·#14·#21), 스트릿 1(#16). 태그와 판정이 11/17로, 남성 클래식 실착(R4, 7/20)보다 잘 맞는다.
- **공식 1(니트 안 셔츠·블라우스 칼라·밑단)**: **0장**(시험용 #15에만 1장). 목 자리는 **터틀넥**(#8 흰·#12 회색), **셔츠 + 넥타이 단독**(#2), **V넥 안 흰 캐미**(#6)가 맡는다. → **실착에 거의 없음.** 남성 R4(공식 3 약함)·R8(셔츠 칼라 0)과 같은 결과다.
- **공식 2(짧은 재킷 + 긴 하의)**: 맞는 착장 4장(#11·#12·#13·#19) + 반만 1장(#4, 코트가 허벅지). 반대(짧은 위 + 짧은 하의) 2장(#8·#16). → **보임(4~5/17).** 짧은 겉옷은 **블레이저·트위드·부클 재킷**이 중심.
- **공식 3(뉴트럴 바탕 + 깊은 색 하나 작은 자리)**: 바탕 뉴트럴(블랙·브라운·크림·회색·네이비)은 15/17. 그러나 깊은 색을 작은 자리에 넣은 착장은 **2장**(#4 버건디 신발·#17 퍼플 가방, 시험용 #15 버건디 가방). 나머지는 **뉴트럴만**으로 끝난다. 밝은 색 큰 면적(#7 버터 옐로 코트)·여러 색 줄무늬(#21)도 있다. → **바탕은 맞고, 깊은 색 포인트는 약함.**
- **공식 4(같은 소재·무늬 위아래)**: 클래식 착장에서는 0장(캐주얼 스웨트 셋업 #14뿐). → **실착에 없음.**
- **관찰 "롱부츠로 하의 끝을 덮는다"**: 신발 보인 6장 중 **0장**(메리제인·더비·탠 미들 부츠·운동화). **크로커 스커트도 0장.** → 둘 다 타임 룩북의 습관으로 보인다(1곳 관찰 그대로).
- **실착에서 새로 본 것**:
  - **블랙 미디·롱 스커트**(새틴·울·부클 짝) + 니트나 짧은 재킷 — 3장(#4·#6·#19), 그레이·데님 롱 스커트까지 넣으면 5장(#11·#13). 미니는 2장(#8·#16).
  - **종아리 롱코트**는 브라운·다크 브라운·버터 옐로 3장(#1·#7·#18) — 룩북의 카멜·브라운 롱코트와 같은 방향.
  - 가방 자리: 블랙 4(#7·#12·#18·#19, 가죽 3·백팩 1) · 브라운 가죽 4(#1·#4·#8·#9) · 퍼플 캔버스 1(#17). **가방은 블랙 아니면 브라운 가죽.**
