# 브랜드 후보 1차 리스트

처음 작성: 2026-11-07. 보강: 2026-11-07 03:23 실행(접근 막힘 대체 작업). 칸마다 상위 3~5개. **근거** 칸에 공개 순위·판매 보도 링크를 단다. 없으면 "근거 없음".
"근거 없음"은 크부장이 알고 있는 후보라는 뜻이고, 인기 순위로 확인한 것이 아니다. 칸을 공부할 때 매체 언급 빈도로 보강한다.
타깃 연령은 **브랜드·매체가 밝힌 것만** 적는다.
