# 한국 · 20대 여성 · 페미닌 · FW (사례 카드)

- **칸 시즌 표기(2026-11-08 정리)**: 칸 이름의 "FW"는 계절 묶음(가을·겨울)이고, 기준 범위는 최근 2년(FW25·FW26)이다. **실제 수집 시즌: FW26 22착장**(전체 22착장). 파일 이름은 원래 `-fw25`였으나 실제 자료와 헷갈리지 않게 `-fw`로 바꿨다.

- 칸: queue #5. 처음 기록: 2026-11-08 03:40 KST 실행.
- 출처 2곳: **마인**(한섬) 2026 F/W No.10·11·12 룩북(12착장), **오즈세컨**(O'2nd, 한섬) 2026 F/W No.5·6 룩북(10착장). **둘 다 한섬 브랜드**다 — README 판정 기준대로 같은 회사의 다른 브랜드는 다른 출처로 세되, 이 점을 노트에 적는다.
- **brands.md 페미닌 후보(오르·럭키슈에뜨·보브·스튜디오 톰보이·시엔느)는 하나도 못 열었다.** 29CM·LF몰·코오롱몰이 막혀 있다(sources.md 0절). 열리는 더한섬닷컴에서 페미닌 쪽 여성 브랜드를 골랐다. 같은 한섬의 SJSJ FW26 No.2·3도 열어 봤지만 미니멀·캐주얼 쪽이라 이 칸에서 뺐다(20대 여성 미니멀·캐주얼 칸 보강 후보).
- 대상: 마인·오즈세컨 모두 이 페이지에서 **타깃 연령을 밝히지 않는다**(→ "미표기"). 마인은 크부장이 아는 바로 20대보다 위 연령대를 겨냥하는 브랜드라 **20대 여성 칸 근거로는 약하다**(크부장 판단, 근거 문서 없음). 사진을 보고 모델 나이를 짐작하지 않았다.
- 시즌: FW26(2026-10~11 공개). 최근 2년 안.
- 사진은 공식 페이지를 클라우드 브라우저로 열어 스크래치 폴더에서만 봤다. 색은 **화면 기준 근사값**이다. 오즈세컨 사진은 흐린 자연광이라 색이 차갑게 보인다.
- 한 룩이 여러 장에 나뉜 경우 합쳐 한 카드로 썼다. 안 보인 자리는 "안 보임".
- 뺀 것: 마인의 니트 조거·후드 셋업(캐주얼 쪽), 퍼 스톨 + 니트 드레스(연출 사진), 니트 플리츠 셋업·카디건 셋업 일부(같은 조합 반복), 오즈세컨의 테디 코트 + 그래픽 티(캐주얼 쪽)·그레이 카디건 + 데님(캐주얼 쪽)·긴 패딩 + 레깅스(같은 조합 반복).
