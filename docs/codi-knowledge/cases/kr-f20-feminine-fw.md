# 한국 · 20대 여성 · 페미닌 · FW (사례 카드)

- **칸 시즌 표기(2026-11-08 정리)**: 칸 이름의 "FW"는 계절 묶음(가을·겨울)이고, 기준 범위는 최근 2년(FW25·FW26)이다. **실제 수집 시즌: FW26 22착장**(전체 22착장). 파일 이름은 원래 `-fw25`였으나 실제 자료와 헷갈리지 않게 `-fw`로 바꿨다.

- 칸: queue #5. 처음 기록: 2026-11-08 03:40 KST 실행.
- 출처 2곳: **마인**(한섬) 2026 F/W No.10·11·12 룩북(12착장), **오즈세컨**(O'2nd, 한섬) 2026 F/W No.5·6 룩북(10착장). **둘 다 한섬 브랜드**다 — README 판정 기준대로 같은 회사의 다른 브랜드는 다른 출처로 세되, 이 점을 노트에 적는다.
- **brands.md 페미닌 후보(오르·럭키슈에뜨·보브·스튜디오 톰보이·시엔느)는 하나도 못 열었다.** 29CM·LF몰·코오롱몰이 막혀 있다(sources.md 0절). 열리는 더한섬닷컴에서 페미닌 쪽 여성 브랜드를 골랐다. 같은 한섬의 SJSJ FW26 No.2·3도 열어 봤지만 미니멀·캐주얼 쪽이라 이 칸에서 뺐다(20대 여성 미니멀·캐주얼 칸 보강 후보).
- 대상: 마인·오즈세컨 모두 이 페이지에서 **타깃 연령을 밝히지 않는다**(→ "미표기"). 마인은 크부장이 아는 바로 20대보다 위 연령대를 겨냥하는 브랜드라 **20대 여성 칸 근거로는 약하다**(크부장 판단, 근거 문서 없음). 사진을 보고 모델 나이를 짐작하지 않았다.
- 시즌: FW26(2026-10~11 공개). 최근 2년 안.
- 사진은 공식 페이지를 클라우드 브라우저로 열어 스크래치 폴더에서만 봤다. 색은 **화면 기준 근사값**이다. 오즈세컨 사진은 흐린 자연광이라 색이 차갑게 보인다.
- 한 룩이 여러 장에 나뉜 경우 합쳐 한 카드로 썼다. 안 보인 자리는 "안 보임".
- 뺀 것: 마인의 니트 조거·후드 셋업(캐주얼 쪽), 퍼 스톨 + 니트 드레스(연출 사진), 니트 플리츠 셋업·카디건 셋업 일부(같은 조합 반복), 오즈세컨의 테디 코트 + 그래픽 티(캐주얼 쪽)·그레이 카디건 + 데님(캐주얼 쪽)·긴 패딩 + 레깅스(같은 조합 반복).

- **크부장 판정 페미닌(근접 포함)**: 11장(#1·#2·#4·#8·#9·#11·#12·#14·#16·#17·#21). 걸리시·Y2K 5장(#6·#7·#18·#22·#23), 시크·캐주얼 3장(#3·#13·#19). "로맨틱" 태그는 페미닌과 걸리시(짧은 하의)가 섞여 있다.
- **공식 1(퍼지는 미디 스커트)**: 하의가 미디·롱 스커트인 착장 **8장**(#1·#2·#4·#11·#12·#16·#17·#21). 그중 **퍼지는 것은 3장**(#1 티어드·#4 머메이드·#17 새틴 약간), 일자에 가까운 꽃무늬 1장(#11). 나머지 4장은 **슬림·드레이프·새틴·스카프 겹친 맥시**다. → **"긴 스커트"는 실착에서도 중심이지만, "퍼지는" 조건은 약하다.** 길이는 종아리보다 길어 발목(맥시)이 많다.
- **공식 2(파스텔 한두 자리)**: 4장(#2 모브 스커트·#8 분홍 니트·#17 분홍 윗옷·#19 민트 카디건). 시험용 2장(#15 라벤더 가방·#20 분홍)도 같은 방향. → **보임.** 큰 자리(니트·카디건·윗옷)에 들어간다.
- **공식 3(칼라를 밖으로)**: 1장(#18). → **약함.** 대신 실착은 **어깨·목선을 드러낸다** — 오프숄더 3장(#1·#2·#14), 캐미솔·슬리브리스를 긴팔 위에 **겹치기** 2장(#4·#17). 얼굴 아래를 밝히는 일을 칼라 대신 **넥라인 노출·겹침**이 한다(크부장 해석).
- **공식 4(코트 허리·밑단 실루엣)**: **0장.** 아우터가 보인 5장(#6·#7·#12·#13·#18)은 모두 **짧거나(크롭·엉덩이) 오버핏**이고 허리를 잡지 않았다. 11월 초라 코트 착장이 적었을 수도 있다.
- **공식 5(다리 한 색)**: 짧은 하의 7장(#6·#7·#8·#9·#18·#22·#23) 중 **다리를 덮은 것 4장**(#6 블랙 니삭스·#9 블랙 리본 시어·#18 흰 타이츠·#23 블랙 시어), 레그워머만 1장(#7), 맨다리 + 롱부츠 1장(#22). 미디 위 니삭스 1장(#4). → **보임.** 색은 블랙이 기본, 흰 1장. 무늬(리본) 1장.
- **신발(보인 10장)**: 로퍼·메리제인·플랫 5장(#1·#6·#8·#9·#18), 부츠 5장(#7 슬라우치·#11 니하이·#16 앵클·#22 흰 니하이·#23 웨스턴). **롱부츠 + 짧거나 미디 하의** 4장(#7·#11·#22·#23) — 노트의 "스커트 + 롱부츠" 관찰과 같은 방향.
- **가방 색**: 갈색·다크 브라운 5장(#1·#6·#7·#8 + #2 브라운), 블랙 5장(#3·#4·#12·#16·#21), 아이보리 2장(#17·#19), 머스터드 1장(#11). R3(캐주얼 실착)과 같이 **갈색 가방이 색 자리**로 자주 나온다.
- **바탕색**: 크림·아이보리·베이지 바탕 5장(#1·#12·#17·#18·#19), 블랙·차콜 바탕 8장(#2·#3·#6·#9·#16·#21·#22·#23). 룩북(마인·오즈세컨)보다 어둡고, R3 캐주얼 실착(14/20 어두운 바탕)보다는 밝다.
