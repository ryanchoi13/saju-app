# 한국 · 40대 남성 · 캐주얼 베이직 · FW (사례 카드)

- **칸 시즌 표기(2026-11-08 정리)**: 칸 이름의 "FW"는 계절 묶음(가을·겨울)이고, 기준 범위는 최근 2년(FW25·FW26)이다. **실제 수집 시즌: FW26 25착장**(처음 12착장 + 2026-11-12 03:23 실행 보강 13착장). 파일 이름은 원래 `-fw25`였으나 실제 자료와 헷갈리지 않게 `-fw`로 바꿨다.

- 칸: queue #8. 처음 기록: 2026-11-08 05:28 KST 실행. 처음엔 **12착장(`부분`)**, **2026-11-12 03:23 실행에서 시스템옴므(한섬) FW26 13착장을 보강해 25착장 → `완료`**.
- **보강 출처(2026-11-12)**: **시스템옴므**(한섬) 더한섬닷컴 룩북 "2026 F/W No.1"(BR07/10052466, 2026-09-07 게시, 실내 스튜디오) 8착장, "2026 F/W No.2"(BR07/10053558, 2026-09-22 게시, 도쿄 거리로 보이는 야외 화보 — 촬영지는 페이지에 없음) 5착장. 코트·수트 재킷 착장(댄디·미니멀 쪽)과 클로즈업·소품 컷은 뺐다. 시스템옴므는 이 페이지에서 타깃 연령을 밝히지 않는다(칸 #6 노트와 같음: 40대 근거 없음). 모델·연출(헤어·선글라스)의 에너지가 높아 40대 근거로는 약하다(크부장 판단).
- **이제 출처는 브랜드 3곳·기업집단 2곳**(삼성물산: 빈폴 맨·에잇세컨즈 / 한섬: 시스템옴므).
- 출처 2곳: **빈폴 맨**(삼성물산 패션) "더 클래식 노트" #1·#2 기획전 3착장, **에잇세컨즈**(삼성물산 패션) 26 F/W 기획전 2개 9착장. **두 브랜드 모두 삼성물산**이다(같은 회사의 다른 브랜드 → 다른 출처로 세되 같은 회사임을 적음).
- 두 브랜드 모두 brands.md 40대 남성 캐주얼 베이직 후보다(빈폴 +20%, 에잇세컨즈 남성 두 자릿수 성장 — 2026 1분기, 다만 **연령 구분 없는 수치**). 이 페이지들에서 **타깃 연령은 밝히지 않는다**(→ "미표기"). 사진을 보고 모델 나이를 짐작하지 않았다.
- **주의(크부장 판단)**: 에잇세컨즈는 SPA 브랜드이고, 이번 기획전은 선글라스·목걸이·넥타이+데님 같은 연출이 많아 40대 남성 실착보다 **에너지가 높은 쪽**으로 보인다. 그래서 넥타이를 맨 "소프트 테일러링" 착장(6컷 이상, 넥타이 + 셔츠 + 재킷)은 캐주얼 베이직이 아니라 댄디 쪽이라 이 칸에서 뺐다. 남은 착장도 40대 근거로는 약하다.
