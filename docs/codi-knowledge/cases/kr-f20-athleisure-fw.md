### 집계 (시험용 4장 제외, 19장)

- **크부장 판정 애슬레저(근접 포함)**: 12장(#1·#2·#3·#8·#11·#12·#14·#17·#18·#19·#22·#23). 캐주얼 3(#4·#13·#21), 스트릿 2(#6·#16), 걸리시 1(#7), 프레피 1(#9). "스포티" 태그와 판정이 12/19로 맞는 편.
- **공식 1(짧은 다운·겉옷 + 운동복 하의)**: 정확히 맞는 것 3장(#1 다운 + 레깅스, #14 셸 + 트랙, #17 플리스 + 스웻), 근접 1(#22). → **보임(3~4/19).** 아우터를 입은 애슬레저 착장 7장(#1·#3·#11·#12·#14·#17·#22)은 **모두 허리~엉덩이 길이** — 롱패딩·롱코트 0. 이 부분은 룩북과 같다.
- **공식 2(파스텔 아우터 + 뉴트럴 하의)**: 파스텔·연한 아우터 4장(#1 스카이블루·#3 라일락그레이·#12·#17 스카이블루). → **보임(4/19).** 다만 **하의 색이 다르다**: 룩북은 차콜·회색·아이보리였는데, 실착은 **네이비·블랙**(#3·#12·#17)이 많다.
- **공식 3(이너·하의 같은 밝은 색)**: 3장(#8 베이지 + 라이트그레이, #18 민트 셋업, #23 회색 원톤). → **보임(3/19).** 룩북의 아이보리 대신 **회색·민트**.
- **공식 4(레깅스 + 흰 크루 양말 + 러닝화)**: 정확히 맞는 것 **0장**. 대신 **"양말을 보이게 신고 운동화"** 는 3장(#1 배색 양말 + 레깅스 + 트레일화, #2 흰 양말 + 쇼츠 + 러닝화, #19 그린 긴 양말 + 쇼츠 + 레트로 운동화). → **약함.** 양말을 보이게 신는 방향은 같고, 레깅스 대신 **쇼츠**가 많다(10월 게시).
- **공식 5(스포츠 아우터·상의 + 비운동복)**: 3장(#4 후드 집업 + 부츠컷 데님, #11 크림 다운 + 데님, #13 래글런 + 와이드 데님). → **보임(3/19).** 섞는 짝은 룩북의 플리츠 스커트·니트가 아니라 **데님**.
- **새로 본 것**:
  - **운동 현장 실착**: 헬스장·복싱장·필라테스 스튜디오에서 찍은 게시가 3장(#8, 시험용 #5, 뺀 그란데라인 게시들). 실착 "애슬레저"에는 **운동하러 가는 차림 그대로**가 섞여 있다 — 룩북(여행·일상 캠페인)에는 없던 쪽.
  - **스카이 블루 플리스**: 같은 상품(챔피온 하트 로고 플리스)을 다른 회원 2명이 광고 표시 없이 올렸다(#12·#17). 둘 다 **네이비 이너·하의**와 짝.
  - **신발**(보인 애슬레저 6장): 러닝화 3(#1·#2·#3), 레트로 운동화 1(#19), 양털 부츠 1(#12), 퍼 메리제인 1(#23). → 러닝화가 절반.
  - **쇼츠 + 맨다리**: 3장(#2·#12·#19). 10월 초중순 게시라 그렇다고 본다 — 11월 이후 실착이면 줄어들 것(확인 안 함).
- **룩북 2곳 → 실착 상품 브랜드 15곳 이상**(일오공칠·케이스위스·챔피온·그란데라인·나이키 ACG·스탠다드에러·느버·락피쉬웨더웨어 등). 플랫폼은 1곳이라 노트에는 "1곳 관찰(실착)".

### 자체 검증 (R11)

- #1·#3·#12·#17·#21을 크게 다시 열어 확인했다. #3 다운은 처음 "연회색"으로 봤으나 크게 보니 **라일락 그레이**라 고쳤다. #12의 신발은 블랙이 아니라 **다크 브라운 양털 부츠**였다. #21은 롱스커트 아래 데님을 겹쳐 입은 것이라 "스커트 + 데님 겹쳐 입기"로 적었다.
- #12와 #17은 같은 상품이지만 화면 표시(키 등)와 장소가 달라 다른 사람으로 보고 둘 다 남겼다.
- 공식 근거 수를 표에서 다시 셌다(위 집계와 같음).
