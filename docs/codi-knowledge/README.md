# 달하 코디 지식서

달하가 코디 전문가로서 말할 수 있는 근거를 모으는 책이다. 패션에 관심 있는 사람이 읽어도
"진짜 전문가다"라고 느낄 수준을 목표로 한다. (2026-10-28 정오님 결정)

- 코디 추천과 코디 문구는 이 책에 근거가 있는 내용만 쓴다.
- 이 책이 다 채워지기 전까지 화면에는 **오늘의 행운 색 두 개**만 보여 준다.
- 모르는 영역은 [커버리지 지도](coverage-map.md)에 빈칸으로 드러내고, 빈칸이 0이 될 때까지 채운다.
- 사용자에게 평가(좋아요·싫어요)를 요청해서 지식을 채우지 않는다.

## 공부하는 순서

전문가가 배우는 순서를 그대로 따른다. 목차는 [curriculum.md](curriculum.md)에 있다.

1. **체계**: 색채학·패션코디네이션 교과 과정(컬러리스트 과정, 의류학 강의)
2. **학술 근거**: 의류학·색채학 논문의 실증 연구
3. **현장 지식**: 패션지 스타일링 기사, 브랜드 룩북, 스타일리스트의 책·강의
4. **실착 데이터**: 실제로 입는 모습의 기록(스냅, SNS 코디 계정)
5. **검증**: 규칙마다 반례를 일부러 찾고, 출처끼리 엇갈리면 그대로 적는다

## 근거 등급

모든 주장 뒤에 `[등급·출처번호]`를 붙인다. 한 주장에 여러 근거가 있으면 모두 적는다.

| 등급 | 뜻 | 예 |
| --- | --- | --- |
| **A** | 실증 연구: 표본과 측정이 있는 학술 논문 | 한국의류학회지 조사·실험 연구 |
| **B** | 이론·정의: 학술 논문이나 교재의 개념 정의 | 배색 기법 정의, 색채 체계 |
| **C** | 전문 현장: 패션지 에디터, 브랜드, 스타일리스트 | 보그·얼루어 스타일링 기사, 룩북 |
| **D** | 참고: SNS 계정, 그래픽 디자인 자료 | 인스타그램 코디 계정, 포스터 배색 가이드 |

- 규칙은 A나 B가 하나 이상 있어야 "확정"이다. C·D만 있으면 "현장 관찰"로 표시한다.
- 출처의 한계(표본이 대학생만, 오래된 연구, 외국 자료 등)는 반드시 같이 적는다.
- 원본 이미지·문장을 길게 옮기지 않는다. 내용을 요약하고 링크를 단다.

## 장(章) 형식

각 장은 `NN-주제.md` 파일 하나다.

1. **한 줄 요약**: 이 장의 결론
2. **본문**: 주장마다 근거 등급과 출처 번호
3. **엇갈리는 근거와 한계**
4. **달하에 쓰는 법**: 이 지식이 오늘의 색·코디 추천에서 무엇을 바꾸는지
5. **아직 모르는 것**: 다음에 조사할 질문(커버리지 지도에도 반영)
6. **출처**: 번호 목록(제목, 저자·매체, 연도, 링크)
