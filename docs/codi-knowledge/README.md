# 달하 코디 지식서

달하가 코디 전문가로서 말할 수 있는 근거를 모으는 책이다. 패션에 관심 있는 사람이 읽어도
"진짜 전문가다"라고 느낄 수준을 목표로 한다. (2026-10-28 정오님 결정)

- 코디 추천과 코디 문구는 이 책에 근거가 있는 내용만 쓴다.
- 이 책이 다 채워지기 전까지 화면에는 **오늘의 행운 색 두 개**만 보여 준다.
- 모르는 영역은 [커버리지 지도](coverage-map.md)에 빈칸으로 드러내고, 빈칸이 0이 될 때까지 채운다.
- 사용자에게 평가(좋아요·싫어요)를 요청해서 지식을 채우지 않는다.

## 공부하는 순서

전문가가 배우는 순서를 그대로 따른다. 목차는 [curriculum.md](curriculum.md)에 있다.

1. **체계**: 색채학·패션코디네이션 교과 과정(컬러리스트 과정, 의류학 강의)
2. **학술 근거**: 의류학·색채학 논문의 실증 연구
3. **현장 지식**: 패션지 스타일링 기사, 브랜드 룩북, 스타일리스트의 책·강의
4. **실착 데이터**: 실제로 입는 모습의 기록(스냅, SNS 코디 계정)
5. **검증**: 규칙마다 반례를 일부러 찾고, 출처끼리 엇갈리면 그대로 적는다

## 근거 등급

모든 주장 뒤에 `[등급·출처번호]`를 붙인다. 한 주장에 여러 근거가 있으면 모두 적는다.

| 등급 | 뜻 | 예 |
| --- | --- | --- |
| **A** | 실증 연구: 표본과 측정이 있는 학술 논문 | 한국의류학회지 조사·실험 연구 |
| **B** | 이론·정의: 학술 논문이나 교재의 개념 정의 | 배색 기법 정의, 색채 체계 |
| **C** | 전문 현장: 패션지 에디터, 브랜드, 스타일리스트 | 보그·얼루어 스타일링 기사, 룩북 |
| **D** | 참고: SNS 계정, 그래픽 디자인 자료 | 인스타그램 코디 계정, 포스터 배색 가이드 |

- 등급은 **자료의 종류**다. A라고 해서 한국의 모든 사람에게 맞는다는 뜻이 아니다. 그래서 결론에는 등급과 별도로 **판정**을 붙인다.

| 판정 | 조건 | 본문에 쓰는 말 |
| --- | --- | --- |
| **반복 관찰** | 서로 다른 A 연구 2편 이상이 같은 방향 | "여러 연구에서 나왔다" + 표본 범위 |
| **조건부 관찰** | A 1편뿐이거나, 초록만 봤거나, 표본이 좁음 | "이 실험 조건에서 관찰됐다" |
| **이론** | B만 있음(정의·원리) | "이론은 이렇게 설명한다" |
| **현장 관찰** | C·D만 있음 | "현장에서는 이렇게 권한다" |

- 판정을 정할 때 함께 본다: 원문(표·수치)을 확인했는가, 표본이 달하 대상(20대 여성·40대 남성 등)에 맞는가, 다른 연구에서 반복됐는가.
- **통계적으로 유의하지 않다 ≠ 효과가 없다.** 원문이 방향·크기를 어떻게 적었는지 같이 쓴다.
- 전부 없다고 쓰지 않는다("아무도 재지 않았다"). "이번 조사에서 찾지 못했다"로 쓴다.
- **관찰 결과와 달하의 운영 판단을 나눈다.** 근거를 참고해 달하가 정한 원칙은 "(운영 판단)"으로 표시하고, 근거가 입증했다고 쓰지 않는다.
- 측정값(인체치수 등)에서 사람들의 생각·고민을 끌어내지 않는다. 나이·성별만으로 개인의 체형·취향을 짐작하는 규칙은 만들지 않는다.
- 지식서에 넣는 것과 달하 코드에 연결하는 것은 따로 정한다. 점수·선택 규칙에 넣으려면 판정이 "반복 관찰"이고 원문을 확인해야 한다.
- (2026-11-01 PR #241 검토로 기준 변경. 01~07장 모두 이 판정과 아래 근거 상태표로 다시 표시했다.)

### 근거 상태표 (2026-11-01 정오님 결정)

장마다 핵심 결론을 표 하나로 모은다. 등급(자료 종류)과 판정 옆에 네 칸을 따로 적는다.

| 칸 | 값 | 뜻 |
| --- | --- | --- |
| **원문 확인** | 전문 / 초록만 / 미기록 | 표·수치를 본문에서 확인했는가. 미기록 = 그 장을 쓸 때 확인 범위를 적지 않음(다음 보강 때 확인) |
| **표본 적합성** | 맞음 / 부분 / 안 맞음 (20대 여성·40대 남성 각각) | 달하 대상 집단과 연구 표본이 맞는가 |
| **재현** | 1편 / 같은 연구진 N편 / 독립 N편 | 같은 방향 결과가 몇 번, 누구에게서 나왔는가 |
| **적용 상태** | 지식만 / 문구 원칙 / 엔진 후보 / 엔진 적용 | 달하에서 어디까지 쓰는가. 엔진 후보 = 규칙 파일·자동 검사에만 있고 화면에는 없음 |

- 판정 "반복 관찰"은 서로 다른 연구 2편 이상이면 붙이되, 같은 연구진이면 재현 칸에 그대로 적는다.
- 초록만 본 연구 하나로는 "조건부 관찰"을 넘지 않는다.
- 엔진 후보·엔진 적용으로 올리려면 위 규칙(반복 관찰 + 원문 확인)을 지킨다. 올린 날짜를 표에 적는다.
- 출처의 한계(표본이 대학생만, 오래된 연구, 외국 자료 등)는 반드시 같이 적는다.
- 원본 이미지·문장을 길게 옮기지 않는다. 내용을 요약하고 링크를 단다.

## 장(章) 형식

각 장은 `NN-주제.md` 파일 하나다.

1. **한 줄 요약**: 이 장의 결론
2. **본문**: 주장마다 근거 등급과 출처 번호
3. **엇갈리는 근거와 한계**
4. **달하에 쓰는 법**: 이 지식이 오늘의 색·코디 추천에서 무엇을 바꾸는지
5. **아직 모르는 것**: 다음에 조사할 질문(커버리지 지도에도 반영)
6. **근거 상태표**: 핵심 결론마다 등급·판정·원문 확인·표본 적합성·재현·적용 상태
7. **출처**: 번호 목록(제목, 저자·매체, 연도, 링크)
