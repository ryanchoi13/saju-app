# 달하 최종 코디 기준 v1.0

확정일: 2026-09-16 · 기준 식별자: `dalha-outfit-1.0`

정오님이 위임한 판단에 따라 기존 합의와 현실 코디 조사를 정리한 달하의 운영 기준이다. 자료마다 다른 취향을 모두 금지·허용 규칙으로 옮기지 않는다. 합리적인 조합을 선택하고, 달하의 단순 도안과 현재 조건에서 설명·재현할 수 있는지를 함께 판단한다. 이제 일반적인 자료 조사는 종료하고 이 기준으로 구현과 검증을 진행한다.

**코디 기준 확정과 운영 배포 완료는 다르다.** 기준과 작업본 코드는 확정했으며, 실제 모바일 사용 검증과 운영 반영은 남아 있다. 자동 검사를 통과한 모든 조합이 미적으로 승인됐다는 뜻도 아니다.

## 1. 적용 범위와 우선순위

- 분류는 **캐주얼 / 비즈니스 캐주얼 / 비즈니스 포멀** 3가지다.
- 같은 조건과 A/B에 대해 **추천 1 / 추천 2**를 제공한다. 추천 2도 같은 현실성·날씨·TPO 제약을 지킨다. Daily/Trend와 화보 구분은 보류한다.
- 승인한 **49종 도안**과 남녀에 필요한 형태를 재사용한다. 새 연령별 도안이나 세부 TPO를 늘리지 않는다.
- 처리 순서는 **조건에 맞는 착장 선택 → 원래 A/B 적용 검토 → 필요한 경우 같은 계열 톤 조정 → 전체 조합·겹침·색 설명 확인**이다.
- 입력 검증, 수트 연결, A/B 출처, C 승인 원칙을 지킨다. 그 안에서 사용자 승인 착장을 일반적인 선호 점수보다 우선한다.
- 자료와 이전 기준이 충돌하면 이 문서의 결정을 우선한다. 과거 보고서·검토 기록은 당시 판단의 이력으로 보존한다.

## 2. TPO별 기본 착장

| TPO | 달하의 기본 방향 | 피할 처리 |
|---|---|---|
| 캐주얼 | 티셔츠·셔츠·니트와 데님·면바지·반바지·스커트·원피스 등 승인 조합. 운동화를 기본 후보로 하되 로퍼·플랫·부츠도 지정 착장에 사용 | 나이가 많다는 이유로 수트 중심으로 만들기, 캐주얼의 모든 신발을 운동화로 덮기 |
| 비즈니스 캐주얼 | 안정색 하의에 단정한 셔츠·니트·재킷. 이너·가방·소품에는 더 넓은 색 선택 허용 | 포멀보다 자유롭다는 이유로 하의 제한까지 없애기 |
| 비즈니스 포멀 | 안정색 수트·재킷·하의, 차분한 이너와 절제된 포인트. 수트 상·하의 동일색 | 강한 원색 수트를 기본 추천, 여성에게 하이힐을 의무화 |

남성 포멀 구두는 옥스퍼드·더비를 사용한다. 여성은 승인 착장에 맞는 단정한 플랫·로퍼·낮은 굽도 가능하다. 모든 직장·면접의 복장 규정을 충족한다고 설명하지 않는다.

연령은 승인된 조합과 편의성 선택에 반영한다. 50대 기본안의 차분한 배색 방향은 유지하되 나이 자체를 색상 금지의 근거로 일반화하지 않는다. 새 연령별 시장 착용률이나 정량 가중치는 만들지 않는다.

## 3. A/B 색상 배치

1. A 원색을 자연스럽게 쓸 수 있으면 큰 면적부터 검토한다. A를 넓게 쓰기 어렵고 B는 가능하면 B를 넓게 쓴다.
2. 원색을 넓게 쓰기 어려우면 작은 부위·소품을 검토한다. 원색이 현실적인 착장이나 TPO와 맞지 않을 때 같은 계열의 착장용 톤을 허용한다.
3. 그래도 어색하면 팔레트로 안내한다. 색을 모두 사용하려고 아이템을 추가하지 않는다.
4. 원래 추천색과 실제 활용색, 적용 아이템·부위, 톤 변경·미적용 이유를 구분해 기록한다.
5. 추가 오행색 C는 코어가 필요성과 허용 여부를 판단한 경우에만 가능하다. 현재 연결 코드는 C를 새로 만들지 않는다. 의류 기본색·금속 표현색을 임의로 C로 부르거나 오행을 재분류하지 않는다.

화이트·그레이·블랙을 시각적으로 차분하다는 이유로 같은 오행으로 취급하지 않는다. 기본 금속 표현색은 소재를 그리기 위한 값이며 실물 제품을 측정한 값이 아니다.

### 색 범위

- 일반 하의 기본 후보: 화이트·블랙·차콜·그레이·네이비·베이지·브라운 등 기존 안정색 범위.
- 데님: 네이비·블루·라이트블루 계열에 **검정 추가**. 이전의 파랑 3색 한정 기준을 대체한다. 임의의 유색 데님까지 확장하지 않는다.
- 보라·빨강·녹색 하의를 기본 추천하지 않는다. 이름을 올리브 등으로 바꾸어 우회하지 않는다.
- 포멀의 큰 면적은 안정색 중심. 브라운 수트는 블랙·네이비·회색 계열보다 낮은 기본 우선순위이며, 두 안을 모두 브라운 큰 면적으로 채우지 않는 방향을 유지한다.
- 봄·가을 코트에 기존 차분한 베이지를 허용한다. 겨울까지 자동 확장하거나 새 트렌치 도안을 뜻하지 않는다.
- 실제 채색값 기준 **2~3색 우선**, 4색 후보는 검토 표시. 시계·넥타이·주얼리의 부위 색도 포함한다. 선·시곗바늘 같은 가독성 표시선까지 의류 배색 수로 세지는 않는다.
- 노랑 줄·테두리와 녹색 문자판의 승인 시계 착장은 5색의 명시적 사용자 예외다. 다른 착장의 5색 허용 근거로 확대하지 않는다.

## 4. 깔맞춤 — 이번에 확정한 판단

깔맞춤은 색의 개수를 줄이는 것만이 아니라 어느 부위를 연결할지 선택하는 방법이다. 맞췄다는 이유만으로 더 높은 평가를 주지 않으며, 맞추지 않았다는 이유만으로 탈락시키지 않는다.

| 관계 | 최종 기준 | 적용 수준 |
|---|---|---|
| 수트 재킷·바지/스커트 | 같은 세트는 같은 색 | 필수 |
| 일반 상·하의·아우터 | 같은 계열에서 밝기·깊이가 다른 톤온톤 허용. 올블랙·올화이트도 가능 | 선택 가능한 조합 |
| 상의·신발, 옷·소품 | 떨어진 위치의 색 반복 허용. 흰 상의·청바지·흰 운동화 같은 연결 | 선택 가능한 조합 |
| 포멀 가죽 구두·벨트 | 둘 다 있을 때 같은 계열 우선. 완전히 같은 HEX는 불필요 | 선호 기준 |
| 신발·가방 | 일치·비일치 모두 허용. 전체 착장으로 판단 | 강제 일치/금지 없음 |
| 강한 포인트 소품 | 기본적으로 같은 강한 포인트는 1~2개에서 정리. 모자·가방·신발 등을 일괄 같은 원색으로 바꾸지 않음 | 반복 과다 후보의 우선순위 하향 |
| 수트·넥타이 | 같은 계열도 허용. 실제 그려진 밝기·무늬로 구분되어야 함 | 도안 가독성 조건 |

‘포인트 1~2개’는 달하 기본안의 보수적인 선택이며 보편적인 복식 법칙이 아니다. 차분한 단색 착장을 포인트 반복 과다와 동일하게 취급하지 않는다. 여성 포멀의 승인 와인 조합은 **와인 백+와인 구두+금 귀걸이**, 또는 **와인 귀걸이+와인 백+블랙 구두**로 보존한다.

넥타이는 무늬까지 결정한 뒤 수트와의 구분을 검사한다. 네이비 수트+네이비 타이도 밝은 줄무늬가 있으면 가능하다. 단순 도안에서 같은 단색 면이 붙어 구분되지 않는 후보는 조정한다. 실물의 소재 차이만으로 구분될 것이라고 가정하지 않는다.

현재 코드에는 세트·톤온톤·상의/신발 반복·가방/신발 관계와 판단 이유가 기록된다. 포멀 가죽 구두/벨트의 다른 색 계열, 같은 강한 소품색의 과도한 반복은 후보 점수에 반영한다. 일치 자체에는 가산점을 주지 않는다.

**구현 범위:** 이미 만들어지는 후보를 평가하는 단계다. A/B를 여러 아이템으로 복제하는 일반 배색 생성기나 새로운 벨트 자동 추가 기능은 아니다. 2색 운동화는 허용 방향으로 보관하되 부위별 운동화 렌더링은 이번 작업에 포함하지 않는다.

## 5. 아이템·날씨·배치

| 대상 | 확정 처리 |
|---|---|
| 신발 선택 | 성별·날씨/계절·TPO에 맞는 완성 착장의 신발을 유지. 임의의 온도 하나로 운동화를 전부 부츠로 교체하지 않음 |
| 넣기·꺼내기 | 정장 셔츠 기본 넣기, 티셔츠·니트 기본 꺼내기. 얇은 니트·티셔츠+스커트 등 승인 예외는 착장별 지정 |
| 챙겨가는 겉옷 | 옆·뒤에 적절한 크기로 배치. 안감/뒷판을 채워 가운데가 배경처럼 뚫리지 않게 처리 |
| 입는 겉옷 | 연결된 상하의 위에 겹침. 열린 앞 사이로 이너를 보이고 안쪽 소매는 중복 노출하지 않음 |
| 코트·패딩 | 승인한 열린 형태 유지. 추운 실외에서는 여며 입도록 안내. 그림이 실제 보온 성능을 증명하지 않음 |
| 원피스 | 상·하의를 대신하며 승인한 무릎 정도 길이 유지 |
| 겨울 치마·원피스 | 필요한 타이츠 표현이 없는 현재 템플릿은 긴바지로 대체. 겨울 치마 자체가 불가능하다는 규칙은 아님 |
| 비 | 기존 비 여부를 사용. 부츠·가죽이라는 이유만으로 방수라고 설명하지 않음 |
| 소품 | 착장에 필요한 것만 선택. 색을 넣거나 빈 공간을 채우려고 추가하지 않음 |

서비스의 현 날씨 모듈은 경주 고정 지점의 체감온도 구간과 기존 낮밤 차이·비·바람 조건을 사용한다. 사용자의 실제 위치에 대한 전국 자동 검증이 완료된 것은 아니다. 이번 확정 과정에서는 세부 날씨 입력이나 분류를 늘리지 않았다.

## 6. 승인 도안과 소품 색

- 얇은 회색 선, 간결한 내부선, 승인한 남녀 실루엣을 유지한다. AI 재생성으로 원본을 대체하지 않는다.
- 패딩은 자연스러운 어깨, 둥근 짧은 몸통, 약간 벌린 팔과 열린 앞을 유지한다. 아래로 보이는 니트는 몸통에서 밑단까지 이어진다.
- 긴바지 길이와 허리 연결, 무릎 원피스, 옷 대비 신발·가방·모자 크기는 승인본 기준이다.
- 모자는 야구모자 형태로 위쪽, 시계는 손목 높이, 귀걸이·목걸이는 상의 왼쪽의 목 근처, 넥타이는 셔츠 위에 한 번만 표시한다.
- 시계는 남녀 기본 비율을 구분하되 색을 성별로 금지하지 않는다. 남성은 조금 넓은 줄·큰 문자판, 여성은 조금 가는 줄·작은 문자판으로 단순화한다.
- 시계 줄/테두리/문자판, 귀걸이 금속/장식, 목걸이 체인/펜던트, 넥타이 바탕/무늬의 색을 독립적으로 전달한다. 그림과 설명은 같은 부위 데이터에서 만든다.
- 49종 명칭과 원래 연구 아이템명·소재·변환 이유를 구별한다. 기존 코트 도안을 트렌치와 완전히 동일하다고 설명하지 않는다.

## 8. 이번 버전에서 보류하는 범위

추가 결정 요청 없이 보류한다. 보류 기능을 표현하기 위해 기존 도안이나 조건을 억지로 바꾸지 않는다.

- 면접·엄격한 행사 등 TPO 세분화, 성별·연령별 새 정량 착용률.
- 강수량·야외 체류시간·활동량·충전재·제품 기능별 세부 보온/방수 모델.
- 타이츠, 앞만 넣기, 새로운 트렌치·레인부츠·긴 원피스 도안.
- 다색 가방 트리밍, 체크 머플러, 운동화의 A/B 포인트 부위, 일반적인 다중 아이템 A/B 반복 생성.
- 새 연구 착장 전체의 자동 활성화. 자료가 있다고 모든 조합이 승인된 것은 아니다.

수정은 실제 오류, 사용 중 발견한 불편, 새로 승인한 기능을 근거로 다음 버전에 기록한다. 상충되는 유행 기사 하나만으로 이번 기준을 뒤집지 않는다.

## 9. 반영 및 확인 결과

- 추천 출력에 기준 버전 `dalha-outfit-1.0`과 깔맞춤 관계·판단 이유를 연결했다. 렌더러 응답 버전은 `approved-svg-4`다.
- 수트·타이 가독성 판단을 부위 색 생성 이후로 이동해 실제 줄무늬를 고려한다. 같은 계열의 바탕색만으로 제외하던 처리를 완화했다.
- Python 검사 **37개 통과**. 실제 배색 풀 120쌍 × 성별 2 × 계절 4 × 착장 6 = **5,760착장**, 기존 연령·가상 날씨 **300착장** 검사가 포함된다.
- 승인된 **5벌의 기본 SVG 해시 유지**. 소품 부위·넥타이 무늬 검사는 별도로 통과했다. 승인 기록을 새 결과로 덮어 통과시키지 않았다.
- 남녀 시계, 부위별 색, 잘못된 색 입력 거부 등 기존 SVG 검사 통과. 같은 네이비 수트·타이와 밝은 줄무늬 사례를 **390px 정적 렌더**로 확인했다.
- 이 검사는 전 조합의 미적 승인, 실제 모바일 브라우저 검증, 실시간 개인 명리·날씨의 실사용 검증이 아니다. 이번 변경의 실제 모바일 확인과 운영 배포는 남아 있다.
- 수치 임곗값과 점수는 구현용 휴리스틱이다. 예를 들어 타이/수트 동계열 명도 차이 0.12, 타이/셔츠 0.13은 SVG 구분을 위한 값이며 논문·실물 측정으로 입증한 최적 수치가 아니다. 소재의 광택·질감은 자동 평가하지 않는다.

재현 파일: `fashion_v2/coordination.py`, `fashion_v2/svg_recommendation.py`, `backend/tests/test_fashion_coordination.py`. 이전 부위 색 구현은 `fashion_v2/realwear_rules.py`와 `assets/dalha-garments/components.js`, `integration.js`에 있다.

## 10. 채택한 근거의 위치

출처는 가능한 조합의 근거이며 이 문서의 정확한 점수·금지 범위·성별 비율을 입증하지 않는다. 상세한 기존 조사는 「달하_확정기준과_추가조사_3차」와 「달하_깔맞춤_조사와_기준안」에 보존한다.

- 같은 계열의 명도·질감 활용: [Style at a Certain Age](https://www.styleatacertainage.com/fashion/tonal-dressing-over-50/). 달하는 질감을 자동 평가하는 대신 도안의 색·무늬 구분을 사용한다.
- 상의와 신발의 반복: [Women.com](https://www.women.com/1823700/how-upgrade-outfits-sandwich-method/). 모든 착장에 강제하지 않는다.
- 포멀 가죽 구두·벨트의 연결: [Cobbler Union](https://www.cobbler-union.com/blogs/journal/how-to-match-belts-to-shoes), [In Corio](https://www.incorio.com/en/content/24-matching-your-shoes-and-belt). 가방·신발 전체의 금지표로 확대하지 않는다.
- 가방·신발이 다른 사례와 맞춘 사례: [Who What Wear](https://www.whowhatwear.com/fashion/trends/handbag-shoes-color-styling-trick-2026), [Woman & Home](https://www.womanandhome.com/life/royal-news/kate-middleton-simple-style-trick-polished/). 어느 한쪽을 정답으로 고정하지 않는다.
- 네이비 수트와 같은 계열 타이: [TieMart](https://www.tiemart.com/blogs/tiepedia/navy-suit-tie-colors). 도안에서 구분되는지는 달하에서 별도로 판단한다.
- 지정 착장에 맞는 부츠 선택: [Hobbs](https://hobbs.com/us/ways-to-wear-ankle-boots.html), [CHARLES & KEITH](https://www.charleskeith.com/my/guides/ankle-boots.html).
- 검정 데님 허용: [Who What Wear](https://www.whowhatwear.com/fashion/outfit-ideas/french-girl-jeans-and-ankle-boots-outfits). 원문의 새 세부 아이템까지 자동 추가하지 않는다.

이번 확정은 기존에 확인한 자료를 종합한 결정이다. 인스타그램 영상 전체 시청이나 모든 출처 사진의 색 측정을 완료했다고 기록하지 않는다.
