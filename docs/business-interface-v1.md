## 구현한 동선

1. 오늘운세 / 나의 사주 / 궁합·고민 / 마이페이지의 4개 하단 탭.
2. 나의 사주: 나의 기본 / 인생 흐름 / 올해·월별. 생년정보 확인은 공통 상단.
3. 나의 기본: 평생운세의 포함 내용과 열람 안내 → 궁금한 주제 → 명식·근거. 새 무료 개인 해석은 만들어 넣지 않는다.
4. 인생 흐름: 현재 구간과 기존 4단계 → 구매한 대운별 풀이 선택 → 같은 평생운세 전체 읽기.
5. 올해·월별: 포함 내용 → 구매한 연도의 월 선택 → 전체 읽기. 현 연도 구매 결과만 현재 월을 기본 선택하며 과거 연도는 1월부터 표시한다.
6. 궁합·고민: 고민 질문 → 관련 기존 상품 → 두 사람 궁합 → 이번 접속에서 읽은 풀이 → 보관함. 전체 주제로 모든 기존 분야에 접근한다.
7. 읽기: 기존 원문 그대로, 목차 이동·인쇄·닫기·Escape·브라우저 뒤로 가기. 원래 내부 메뉴와 초점·스크롤 위치로 돌아간다.

## 내용·권한 경계

- 원국·일진·대운 계산과 리포트 해석 문장은 변경하지 않았다. 서버 리포트에는 월·대운 선택을 위한 HTML 표지만 추가했다.
- 유료 본문은 이미 서버가 돌려준 구매 목록에서만 꺼낸다. 미구매자에게 월별·대운별 본문을 새로 전달하거나 노출하지 않는다.
- 구매 결과는 구매 당시 결과라고 표시한다. 프로필 수정·연도 변경을 이유로 기존 리포트를 재해석하거나 무료로 재생성하지 않는다.
- 구형 리포트에 월·대운 표지가 없으면 전체 읽기로 제공한다. 제목에서 월별 내용을 추측해 분할하지 않는다.
- 같은 리포트의 재열람은 구매 요청을 보내지 않는다. 요청 중 연속 클릭은 프런트에서 막고 실패 시 버튼을 복구한다. 네트워크 응답 유실 뒤 서버의 중복 차감을 막는 작업까지 완료한 것은 아니다.
- 궁합은 현재 지원하는 연인·부부의 관계로 설명한다. 가족·동료용으로 문구만 바꾸지 않는다.
- 캘린더·메모·가족 프로필·AI 상담·5번째 탭·신규 가격과 구독은 후속 과제다.
