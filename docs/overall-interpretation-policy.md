# 총운 공통 해석 원칙

2026-09-10 · 오늘·올해·월별·평생 총운에 공통 적용

## 합의한 목적

근거가 충분한 내용 중 사용자가 먼저 살펴볼 것을 앞에 둔다. 일·성과를 기본값으로 삼지 않는다. 첫 번째와 두 번째 탭은 삶의 여러 영역을 종합하고, 세 번째 탭의 개별 테마는 선택한 분야를 상세히 설명한다. 제목에서 다루지 못한 중요한 다른 내용은 본문에 남긴다. 시간대 안내와 조언을 모두 한 분야로 묶거나 문장 수를 고정하지 않는다.

## 공통 구조

`출생·시간 계산 및 원국 판단 → 기간에 맞는 근거 선택 → 생활 분야 후보 및 우선순위 → 화면별 문장`

- 공통 모듈: `backend/app/engine/semantic/overall.py`.
- 문장 모듈: `backend/app/engine/services/overall_narrative.py`.
- 기존 달력·강약·합충·조후·종합 판단의 결과를 바꾸거나 출력 다양성을 위해 판정을 보정하지 않는다.
- 관계의 직접 구성원뿐 아니라 기존 코어가 추적한 원국의 뿌리·천간 역할 대상도 후보 해석에 연결한다. 같은 관계의 다른 설명이므로 독립 근거로 중복 가산하지 않는다.
- 오늘은 원국+대운+세운+월운+일진, 월별은 원국+대운+세운+월운, 올해는 원국+대운+세운, 평생 기질은 원국, 생애 구간은 원국+해당 대운을 사용한다.
- 넓은 기간의 해석에서 좁은 기간의 신호를 읽지 않는다. 시간 범위마다 기존 조건 검사를 다시 수행한다. 미래 대운을 현재 대운과 겹쳐 읽지 않는다.

## 분야와 사용 범위

| 분야 | 현재 후보를 만드는 자료와 범위 |
|---|---|
| 애정·가까운 관계 | 기존 애정 서비스에서 쓰던 일지 관계 맥락을 활용. 원국 일지와 해당 시간축의 직접 합·충 연결 또는 원국의 직접 연결을 가까운 관계의 대화·거리 조절이라는 조건부 주제로 번역. 삼합 등에 일지가 포함됐다는 이유만으로 애정을 주제로 올리지 않음 |
| 대인관계 | 원국과 연결된 동료·표현 역할, 기간의 해당 역할, 사용 가능한 소통·중재 방향 |
| 재물 | 재성의 기간 맥락과 원국 연결. 지출·구매·계약·투자의 조건을 살피는 제안이며 수익률·자산 가격·횡재를 예측하지 않음 |
| 직장·사업 | 관성 등 역할·책임 맥락과 원국 연결. 사용자를 일률적으로 직장인이나 사업자로 가정하지 않음 |
| 학업·배움 | 인성의 기간 맥락과 원국 연결. 배움·질문·실습에 대한 제안이며 합격·성적을 확정하지 않음 |
| 건강·생활 리듬 | 차단되지 않은 개인 보완 방향과 해당 기간의 회복 맥락. 또는 같은 기간에 함께 놓인 책임·보충 역할의 낮은 수준 생활 해석. 질병·장기·체질·사고·치료를 예측하지 않음 |
| 취미·즐거움 | 식상의 만들기·돌봄·표현 맥락을 업무 생산에 한정하지 않고 일상 만족으로도 번역 |
| 마음·자기 기준 | 비견·일간의 독립성과 선택, 원국 연결. 생각이나 감정을 실제로 알아낸 것으로 서술하지 않음 |
| 이동·생활 변화 | 원국에 연결된 충을 계획 변경을 살피는 조건부 주제로 활용. 이사·부동산 거래가 실제 발생한다고 판단하지 않음 |

모든 분야를 검토한 상태는 내부 `considered_domains`에 남긴다. 구체적 근거가 없는 분야에는 `no_specific_support`를 기록하고 채우기용 문장을 출력하지 않는다. 투자·부동산은 별도의 검증된 예측기가 생긴 것으로 홍보하지 않는다.

## 우선순위

가중치 합산이나 예측 확률이 아니라 다음 순서의 사전식 비교다.

1. 근거 단계: 사용 가능한 개인 보완 방향 / 조건 확인을 거친 원국-기간 연결 / 기간의 상징적 역할.
2. 그 안에서 코어가 명시한 우선 필요도. 미확정·차단된 보완 방향에는 긴급도를 부여하지 않는다.
3. 주제에 직접 연결되는 정도: 가까운 관계를 다루는 직접 일지 연결과 일반 역할 맥락을 구분한다.
4. 해당 기간의 역할 맥락과의 일치.
5. 더 긴 기간의 맥락과의 일치. 긴 기간의 맥락은 후보가 없는 새 분야를 만들 수 없다.

같은 근거가 여러 후보에 걸리거나 여러 번 들어와도 점수를 더하지 않고 가장 높은 단일 근거를 사용한다. 순위가 같으면 공동 주제로 표시하며, 알파벳 정렬을 의미 있는 우선순위로 가장하지 않는다. 다른 중요한 분야에 별도 근거가 있으면 보조 내용으로 남긴다. 반복을 줄이기 위한 무작위 선택·분야 할당량·날짜 해시를 사용하지 않는다.

이 순서는 **달하의 편집·설명 정책**이다. 현실 사건의 발생 가능성이나 영향 크기가 검증됐다는 뜻이 아니다. 조건을 확인한 합·충도 실제 유불리와 사건 영역의 확정 판정으로 승격하지 않는다. 건강 영역의 코어 우선순위는 의학적 긴급도가 아니다.

## 자료와 근거의 경계

주 참고 계통은 기존 합의와 동일한 『적천수천미』 임철초 주석 계통이다. 이번에는 [원문 전재의 육친론 「부처」와 「질병」](https://zh.wikisource.org/zh-hant/滴天髓闡微)을 확인했다. 두 장은 각각 전체 배합과 조건을 살피는 전통적 논의를 포함한다. 이를 현대 애정 사건의 확률이나 의학적 건강 예측의 검증 자료로 사용하지 않는다.

직접 일지 연결의 서비스 적용은 기존 `love.py`의 일주 관계 맥락을 좁혀 활용한 개발 정책이다. 위 원문이 이 구현의 우선순위·일일 소통 문구·성별을 가정하지 않는 현대 관계 표현까지 제시했다고 주장하지 않는다. 질병장의 장기·질병·수명 판정은 서비스에 옮기지 않았다. 생활 분야 번역과 문장들은 서비스 목적에 맞춘 제안으로 분리한다.

## 완료 검증

- 분야 후보에서 제목·본문·조언까지 이어지는 실제 호출을 확인한다.
- 같은 원국과 기간의 결정성을 확인하고 중복 근거가 순위를 올리지 않는지 검사한다.
- 일진 변경이 연간·평생 해석에 섞이지 않는지, 과거/미래 대운이 현재 대운에 의존하지 않는지 검사한다.
- 보완 방향의 미확정·충돌·차단, 생시 미상, 출생 전 기간을 검사한다.
- 대표 프로필들의 일별·월별·대운 출력과 기존 메뉴·코디·개별 테마·프로필 흐름을 확인한다.
- 코드 검사 통과와 실제 예측의 정확성 검증을 구분해 보고한다.

구현 버전: `overall-life-domains-v1`. 운영 배포의 최종 커밋과 확인 결과는 배포 기록에 별도로 남긴다.
