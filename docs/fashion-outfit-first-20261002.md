# 코디 우선 · 추천색 선택 활용

2026-10-02 사용자 검토 후 구현한 변경안. 원칙: 기본 코디 → 추천색 적용 후보 → 전체 착장 재평가.

## 바꾼 이유

이전에는 와다 두 색 조합이 추천색의 입구였고 A/B를 사용하면 높은 점수를 받았다. 오늘의 노랑 블루종·핑크 이너, 핑크 블루종·노랑 후드에 대한 반려 의견처럼, 색을 다 넣는 목적이 기본 옷차림보다 강해질 수 있었다.

추천색은 명리 공통 상태에서 받은 두 오행과 기존 실용 팔레트를 연결해 독립적으로 고른다. 오행 판단 자체는 변경하지 않는다. 같은 날·같은 오행 입력은 같은 색을 쓰며 TPO 변경으로 색이 바뀌지 않는다. 기존 141색 아카이브는 보존하고, 자동 일일 추천의 시작 후보는 기존 실용 팔레트의 오행이 지정된 색이다.

와다 조합은 결과에 일치하는 참고 정보가 있으면 기록하는 후순위 자료다. 일치 자료가 없거나 모듈을 사용할 수 없어도 추천이 동작하며 착장 결과는 같다. 현재는 참고 정보를 근거로 점수를 올리지 않는다. 와다 근접 배색을 새로운 후보로 제안하는 확장은 후속 검토 대상이다.

## 추천 순서

1. 날씨·성별·연령·TPO 템플릿의 아이템·소재·착용 방식을 유지하며, 기본 의복색과 면바지 대안 등을 먼저 준비한다.
2. 추천색을 그대로 쓰거나 등록된 인접 톤으로 조정하는 후보와, 기본 배색을 유지하는 후보를 함께 비교한다.
3. 신발까지 포함해 아이템 현실성, 큰 색 면적의 충돌, 기존 배색 검사와 색상 수를 평가한다. 이 품질 순위가 A/B 사용보다 앞선다. 같은 품질에서 A, B 활용을 비교하고, 기본 의복색을 덜 바꾸는 안을 우선한다.

초기 현실성 평가는 `practical_policy.json`의 명시적인 편집 기준이다. 0.1 아카이브의 미평가 칸을 채우거나 실측 착용률로 승격한 것이 아니다. 미적 완성도를 자동 승인하지 않는다. 이전에 명시적으로 승인된 착장은 적용 범위를 기록한 예외로 유지한다.

## 이번 검토 메모 반영

- B01/B02: 노랑·핑크를 동시에 상체의 큰 면적에 배치하는 기본안은 후순위. 노랑/핑크 블루종과 컬러 운동화 사용을 강제하지 않는다.
- B03: 핑크 이너·베이지 하의에 대한 조건부 의견이다. 검정 겉옷까지 승인한 것으로 보지 않는다.
- B04: 해당 남성 기본안에서는 흰색·검정 운동화를 우선 비교한다. 다른 색을 아무도 신지 않는다는 통계나 전면 금지 규칙은 만들지 않는다.
- B05: 네이비 겉옷·흰 이너·베이지 바지·흰 운동화를 무난한 출발점으로 본다. 버튼의 `revise`와 본문의 긍정적 평가를 함께 보존한다.

베이지 변환은 이번에 논의한 옅은 노랑 두 색값만 명시적으로 연결한다. 모든 노랑을 베이지로 바꾸지는 않는다. 밝은 회색 겉옷을 기본 배색의 추가 후보로 두며, 소재가 다른 바람막이로 아이템 명칭을 임의로 바꾸지 않는다.

## 보이지 않는 추천색 활용

겉으로 보이는 착장에 자연스럽게 넣지 못한 추천색이 있으면 다음과 같은 선택형 문구를 표시한다.

> 오늘 추천색인 보라 계열을 옷차림에 넣기 부담스럽다면, 원하실 때 속옷처럼 겉으로 드러나지 않는 곳에 활용해 보세요. 나만 아는 색으로 기분을 내는 방법도 있어요.

두 색이 남으면 “A 또는 B”로 안내한다. 속옷을 착장 그림에 추가하지 않으며, 색상 개수·실제 적용 위치·추천색 사용 점수에도 더하지 않는다. 실제로 그 색을 입었다고 간주하지 않는다. 특정 성별·연령에 한정하지 않으며 운이 좋아진다고 단정하지 않는다.

## 확인할 결과

`scripts/build_outfit_first_review.py`의 고정 사례는 기존 노랑·핑크 두 안, 새 엔진으로 만든 두 안, 보라를 선택형 속옷 안내로 돌린 두 안이다. 실제 운영 일러스트 렌더러로 그려 색상과 안내 문구를 함께 확인한다. 고정 사례의 가을 조건은 실제 오늘의 기온을 뜻하지 않는다.

API는 `daily_color_palette`를 정식 이름으로 제공한다. 구버전 클라이언트를 위한 `wada_palette` 필드에는 같은 데이터가 들어가지만 와다 조합이라는 의미는 없다. 속옷 안내는 `color_strategy.private_color_suggestion`이며 선택 사항이다.
