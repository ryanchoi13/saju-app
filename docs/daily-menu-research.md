# 오늘의 메뉴 추천 근거와 경계

## 적용 원칙

- 명리 코어가 정한 보완 방향을 첫 축으로 사용한다.
- 전통 식치의 오행·오미·한열·조습은 생활 해석의 참고 체계로만 사용한다.
- 특정 음식의 치료 효과나 건강 효능을 주장하지 않는다.
- 현대 메뉴는 주재료, 조리법, 계절, 시간대, 국내 인지도와 접근성을 함께 본다.
- `화=매운 음식`, `수=해산물`처럼 하나의 표지만으로 음식을 결정하지 않는다.
- 추천 2개 중 적어도 하나는 그날의 중심 재료군을 대표하게 한다.
- 시간대에 맞지 않는 메뉴는 점수와 관계없이 우선 후보에서 제외한다.

## 국내 인지도 기준

한국소비자원의 배달앱 이용 실태조사에서 치킨은 주요 주문 음식 중 가장 높은 비중으로
보고됐다. 치킨, 피자, 햄버거, 샌드위치 업종은 배달앱 이용 비중도 높게 나타난다. 따라서
이들 일상 메뉴를 낮은 인지도의 해외 음식보다 우선 후보로 둔다.

## 술·담배의 분리

술과 담배는 음식 추천, 행운의 아이템에 포함하지 않는다. 향후 별도의 생활 주의 또는
선택형 테마운에서 검토한다. 전통 의학에서는 술을 따뜻하고 발산하는 성미, 약재의 작용을
돕는 매개로 설명한 기록이 있지만 과음의 손상도 함께 경고한다. 약술·약재 가공의 맥락을
현대의 일반 음주 추천으로 직접 바꾸지 않는다.

## 아직 구현하지 않는 항목

- 충·합·역마 등에 따른 익숙한 음식과 새로운 음식의 선택
- 술 종류, 안주, 음주 주의 문구
- 흡연 관련 생활 주의 문구
- 개인의 실제 선택 이력을 이용한 선호 학습

이 항목들은 직접 근거와 달하 자체 해석 규칙을 구분한 뒤 별도 버전에서 구현한다.
