# 사주·고민 탐색 개편 — 2026-10-01

사용자 요청: 메뉴와 문체, 배치를 사례 조사부터 구현·검증까지 맡아 진행. 기존 4개 탭과 상품을 유지하면서 2·3번 탭의 탐색을 완성한다.

## 참고한 공식 사례

2026-10-01 KST 확인.

- [포스텔러](https://app.forceteller.com/): 현재의 질문을 제목으로 제시하는 콘텐츠 탐색과 월별 콘텐츠 진입. 달하에는 질문형 주제 선택에 적용했다. 문구나 이미지는 복제하지 않았다.
- [신한라이프 운세/사주](https://www.shinhanlife.co.kr/hp/cdhg0130.do): 월간·평생 등 기간별 메뉴와 애정/궁합 분리. 달하의 ‘성향 / 인생 흐름 / 올해·월별’와 개인 애정운·두 사람 궁합 구분을 명확히 하는 데 참고했다.

위 사례는 서비스 구조 참고이며 전환율·만족도 효과를 입증한 자료는 아니다.

## 적용

- 사주: 상단 설명을 줄이고 내부 메뉴를 위로 이동. 처음 읽는 사람의 길잡이는 ‘나의 기본’ 안에 배치한다. 일반 읽기 안내를 개인 성향 분석처럼 표시하지 않는다.
- 평생·연간: 무엇을 읽는지 3개 목차로 미리 안내한다. 가격을 일관되게 표시하고, 서버가 반환한 구매 결과가 있으면 ‘구매한 풀이’로 전환한다.
- 올해·월별: 지원되는 구매 결과에는 이번 달(같은 연도) 또는 구매 연도의 월별 풀이로 바로 들어가는 버튼을 제공한다. 예전 결과의 연도를 올해로 바꾸지 않는다. 구형 결과는 원문 전체 읽기를 유지한다.
- 고민: 일·진로, 애정·관계, 돈·생활, 학업·시험, 생활 리듬의 질문형 선택지. 선택하면 해당 리포트 제목으로 이동하고 목차·범위·가격을 보여준다. 선택 자체로 구매 요청을 보내지 않는다.
- 궁합: 바로가기와 독립 카드를 두고, 두 사람 분석임을 명시한다. 기존 상대 입력과 350복채 상품을 재사용한다.
- 문체: 안내는 자연스러운 해요체로 정리. 대운은 ‘10년마다 바뀌는 흐름’으로 설명하며 명식·계산 근거는 기존 펼침 영역에 보존한다.
- 재열람: 기존 보관함·뒤로 가기·상황 선택·구매 API 유지. 소유 결과가 사라지면 숨겨진 대운/월별 DOM도 비운다.
- 접근성: 질문과 결과의 aria-controls 연결, 결과 제목 포커스, 내부 탭 키보드 이동, 명확한 선택 표시, 44px 이상 행동 영역.
- 예시 화면: 현재 코디 데이터 구조와 연간 리더 구조를 사용하도록 예시를 갱신한다. 실제 계정·결제·저장 요청 없이 동작한다.

## 범위

서버 가격 대조: 평생 450, 연간 300, 주제별 220, 궁합 350. 가격·계산·결제 정책·새로운 예측 상품을 변경하지 않는다. 홈 운영 마크업은 직전 배포와 동일하다.

- `python -m unittest backend.tests.test_reading_editorial backend.tests.test_annual_reader backend.tests.test_second_tab_reports -q`: 25개 통과.
- `node scripts/test_fashion_illustrations.mjs`: 기존 추천 이미지 매칭·실패 처리 회귀.
- `test_design_comparison.cjs`의 과거 홈 메뉴 기대값은 현재 메뉴 컴포넌트와 달라 실패한다(예시의 menu-photo-card 2개 기대). 이를 시각 검증 통과로 계산하지 않는다. 변경한 읽기 영역은 별도 DOM 검사와 운영 예시 브라우저에서 확인한다.

배포 후 실제 운영 예시에서 탭·고민 선택·월별 리더·복귀 동선을 확인한다. 로그인된 실제 고객 계정의 결제나 개인 결과는 이 작업에서 생성하지 않는다.
