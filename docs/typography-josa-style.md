# 글꼴·조사·소품 매칭 후속 수정

2026-09-10, PR #47 이후 사용자 피드백 반영.

- 화면 글꼴을 Pretendard 고딕체로 통일하고 명조 웹폰트 다운로드를 제거했다. 별도 인쇄 창도 고딕체로 표시한다.
- 공통 작은 글씨 선택자의 과도한 우선순위가 일진 본문 크기를 덮어쓰던 문제를 해결했다. 제목 24~26px, 본문 17~18px, 시간대 15px을 기본으로 한다.
- 색상 칩 두 개는 같은 행에 놓고 한국어 색상명·상의/하의 역할을 표시한다. 긴 이름은 칩 안에서 줄바꿈하며 영문 원명·HEX는 title에 보존한다. 반전 포인트가 있는 경우 별도 다음 행으로 유지한다.
- es-hangul 2.4.0의 josa만 번들해 단일 HTML에 포함했다. npm 의존성과 잠금 파일, 재생성 스크립트 및 MIT 라이선스를 함께 보관한다. 운영 요청 시 외부 CDN이나 Node 실행은 필요 없다. 공식 소스: https://github.com/toss/es-hangul
- Python 문장 생성은 공통 조사 함수를 사용해 색상·연간 주제·일일 문장에 적용했다. 완성된 문장을 무조건 치환하는 맞춤법 교정기가 아니라, 동적 단어를 붙일 때 조사를 선택한다. 임의 외국어 이름의 발음을 추정하지 않는다.
- 소품 매칭은 후속 합의 검토를 반영해 다시 수정했다. 선택한 TPO → 종류·소재 적합성 → 해당 소품에 자연스러운 색상 → 오늘 팔레트와 보유 소품 대조 순서다. 행운 아이템 이름·소재·날짜를 소품 선정에 사용하지 않는다.
- 적합한 보유 소품이 없거나 종류·소재 정보가 부족하면 추천하지 않는다. 임의 대체 소품이나 구매 권유를 표시하지 않는다.
- 캐주얼/비즈니스 캐주얼/비즈니스 포멀 선택을 추가했다. 현재 브라우저에서 계정별로 저장·복원한다. 기기 간 동기화는 이번 범위가 아니다.
- 기존 배색 평가를 재사용해 TPO별 활용 위치를 서버가 제공한다. 남성 포멀은 상하의 색을 다른 정장으로 강제 배치하지 않는다. 자연스러운 위치가 없으면 착장 적용을 생략한다.

## 확인

기존 화면 동작 9개 시나리오, 프런트 조사·소품·색상 회귀 검사, Python 조사·일진·2번 리포트·TPO 15개 검사 통과. 1978-03-13 10:30 남성 입력으로 2026-09-10~14를 계산했을 때 펜·크로스백·파우치·텀블러·시계로 아이템이 달라졌다. 이는 해당 입력의 재현 검사이며 운영 계정 저장값을 조회한 것은 아니다.

TPO 검사는 120개 배색의 남녀 비즈니스 착장 위치와 색상 보존, 포켓 스퀘어 제외, 옷장 조건 미충족 시 추천 생략, 행운 아이템과의 독립, 선택 저장·계정 분리를 포함한다. 실제 브라우저 렌더링·휴대폰·운영 구매 검수는 실행하지 않았다. 계산 기준과 구매 정책은 변경하지 않았다.
