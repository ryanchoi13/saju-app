# DALHA 전체 브랜드 디자인 — 2026-10-01

Higgsfield를 활용해 UI 전체, 폰트·색상·아이콘·로고를 완성본 기준으로 정리해 달라는 사용자 요청에 따른 개편.

## 시각 방향

Higgsfield에서 세 화면의 시각안, 달/수평선 로고, 달빛 풍경을 생성했다. 출처와 작업 ID는 `assets/brand-2026/provenance.json`에 있다. 실제 화면은 읽을 수 있는 HTML과 조작 가능한 버튼·폼으로 구현했다.

- 아이보리 #F8F6F1 / 남색 #25364A / 살구 #E4B28F. 보조 글씨 #59636D, 강조 글씨 #995737.
- 본문 Pretendard, 대표 제목 Noto Serif KR. 한자·숫자와 긴 본문의 가독성을 위해 본문은 16px 중심으로 유지한다.
- 달 로고와 favicon/touch icon, 24px 일관된 선 아이콘. 장식 아이콘은 접근성 트리에서 제외하고 버튼 이름은 실제 텍스트로 보존한다.
- 오늘의 운세는 남색 대표 영역. 옷차림·식단은 흰 카드, 생활 안내는 구분선과 목록으로 위계를 나눈다.
- 사주는 달빛 풍경이 있는 표지와 목차. 고민은 아이콘·분야·질문·화살표 순서의 한 열 목록.
- 마이페이지, 로그인, 입력 폼, 충전·궁합·상황 선택·코디·리포트 팝업까지 같은 토큰 사용.
- 940px 이상은 홈 두 열 구성. 모바일 하단 메뉴 유지, 데스크톱은 하단의 작은 내비게이션. 확대와 작은 화면 줄바꿈, 모션 감소 지원.

## 안전한 적용 경계

기존 DOM ID, 추천 데이터·색상, 계산·구매·로그인 API를 보존한다. 새로운 브랜드 CSS와 장식 아이콘을 적용했으며 옷 그림, 팔레트, 음식 사진, 오행 색상에 전역 필터를 사용하지 않는다. 광고 자리 표시만 숨기며 실제 광고 iframe/ins가 있으면 숨기지 않는다.

`brand.css`가 새 디자인의 토큰과 최종 시각 규칙이다. 기존 컴포넌트의 동작용 스타일은 유지한다. 이전 clear/moonlight 주소도 같은 journal 브랜드를 표시한다. `/design/compare`는 320/360/390/520/1000px에서 실제 예시 앱을 iframe으로 표시하는 검증 화면이다.

## 검증

- UI 12개 시나리오: 기존 홈 동작 연결, 계정 결과 초기화, 고민/상황 선택, 구매한 리포트 재열람, 중복 요청, 뒤로 가기.
- 연간 리더: 실제 가상 인물 계산 결과로 12개월·6개 분야, 연도·원문 보존, 월별 바로가기.
- 코디: 원본 추천 요약, 팝업/두 추천 전환, 팔레트 한 번 표시.
- 식단: 현재 3끼·3세트 계약에 맞게 낡은 테스트 갱신. 중복 요청, 실패 후 결과 유지, 이전 세트 무료 탐색, 한도, 모드 변경, 계정 초기화 중 도착한 응답 무시.
- 공개 예시: 모든 리소스를 로컬로 읽는 DOM 검사. 실제 계정 저장소 보존, 실제 구매 요청 0건, 탭/팝업/월별 리더/포커스, 같은 브랜드 적용.
- 로그인: CTA·폼·실제 정보 채움·계정 조회 연결 보존. 로고는 로그인 전 개인 화면을 열지 않는다.
- CSS 파싱: esbuild. 핵심 텍스트 대비 5.15:1~11.4:1, 어두운 대표 영역 본문 10.02:1.

운영 배포 후 실제 브라우저의 휴대폰 폭 iframe과 넓은 화면에서 최종 시각 검증한다. 가상 예시와 실제 고객 계정 검증은 구분한다.
