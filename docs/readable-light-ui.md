# 밝은 화면·가독성 개편

2026-09-10. PR #46 이후 중단된 디자인 개선을 이어서 구현했다.

## 방향과 범위

사용자가 이전에 만든 「달하, 오늘의 운세와 일상 추천」 시안의 밝은 배경, 남색 본문, 청록 강조, 흰 카드와 여백을 기준으로 네 탭과 로그인·입력·리포트 화면을 정리했다. 이미지 안의 예시 옷·음식·운세를 실제 개인 결과로 복사하지 않는다.

- 오늘 운세는 흰 카드와 큰 제목, 본문, 구분된 시간대 안내로 정리했다.
- 추천 메뉴는 기존 카드 안에서 한 줄 전체 폭을 사용하고, 아이템·숫자·방위는 비교하기 쉽게 나란히 표시한다.
- 본문은 1rem, 반복 사용하는 설명·선택기는 최소 .875rem을 기준으로 하고, 주요 결과는 더 크게 표시한다.
- 2번 내부 메뉴는 밑줄로 선택 상태를 표시하고, 주제 선택과 리포트 버튼은 청록색으로 통일했다.
- 모바일 하단 안전 여백, 작은 화면의 목록 줄바꿈, 키보드 초점과 모션 감소 설정을 반영했다. 기존 확대 금지 viewport 설정을 제거했다.

기존 단일 HTML 배포 구조를 유지하고, 기존 CSS 뒤에 테마를 추가했다. 작은 인라인 글씨는 서버 응답 후 만들어지는 화면도 포함해 범위를 제한한 CSS로 보정한다. 별도 정적 파일 라우트나 새 의존성은 필요하지 않다.

## 검증과 한계

- 기존 오프라인 인터페이스 9개 시나리오 통과: 오늘 탭 HTML 보존, ID 중복·누락, 내부 탭·키보드, 주제·상황 선택, 구매 권한, 구매 연도, 재열람, 뒤로 가기, 중복 요청·실패 처리.
- 기존 인라인 JavaScript와 오늘 탭 HTML은 그대로이며, 계산 엔진·API·가격·구매 정책은 수정하지 않았다.
- HTML에 추가한 CSS 파싱과 변경 파일 공백 검사 통과.
- 실제 브라우저 렌더링, 휴대폰, 운영 계정 로그인·구매 검수는 실행하지 않았다. 자동 동작 검사 통과를 시각 검수 완료로 표현하지 않는다.
