# 패션 v2 날씨 연동 2단계 — 옷 두께별 완성 코디 선택

## 결정 사항

- 달력의 봄·여름·가을·겨울은 색감과 분위기 참고값으로만 사용한다.
- 실제 옷 두께는 경주 당일의 체감온도 구간으로 선택한다.
- 낮에는 덥고 저녁에는 선선한 날은 `낮 기본 착장`과 `휴대 겉옷`을 분리한다.
- 휴대 겉옷은 하루 종일 입은 모습처럼 코디 이미지에 겹치지 않는다.
- Daily와 Trend는 겉옷뿐 아니라 상의, 하의 실루엣, 신발까지 다르게 구성한다.
- 비가 오는 날은 스웨이드 신발을 생활방수 가죽 신발로 대체한다.
- 비즈니스 포멀은 재킷을 임의로 휴대 처리하지 않고 서머 수트의 한 벌 구성을 보존한다.

## 더운 낮·선선한 저녁 예시

안내 문구:

> 낮에는 반팔이 알맞아요. 저녁에는 얇은 바람막이나 긴팔 셔츠를 챙기세요.

남성 캐주얼 Daily:

- 반팔 폴로
- 경량 스트레이트 팬츠
- 가죽 운동화
- 얇은 바람막이 — 휴대

남성 캐주얼 Trend:

- 반팔 니트
- 세미와이드 경량 팬츠
- 레트로 가죽 운동화
- 얇은 오버셔츠 — 휴대
