# 패션 v2 2단계: A/B 색상 적용

## 핵심 우선순위

`큰 면적 → 중간 면적 → 작은 면적 → 보유 소품 → 팔레트`

- A는 먼저 검토하지만 큰 면적 전용이 아니다.
- A가 작은 면적에만 어울리고 B가 큰 면적에 어울리면 B를 메인으로 사용한다.
- A와 B 둘 다 큰 면적에 어울리고 충돌하지 않으면 둘 다 사용할 수 있다.
- 원색이 과하면 같은 계열의 실제 착장 가능한 색을 쓰고, 원본 A/B는 팔레트에 그대로 남긴다.
- 둘 다 넣으면 어색한 경우 억지로 사용하지 않는다.

## TPO 규칙

- 캐주얼: 상의·아우터·팬츠·원피스의 큰 면적을 넓게 검토한다.
- 비즈니스 캐주얼: 니트·셔츠·가디건·재킷·스커트를 먼저 검토하고 순차적으로 면적을 줄인다.
- 남성 비즈니스 포멀: A/B 중 네이비·차콜·그레이 수트와 가까운 색을 메인으로 먼저 검토한다. 화려한 색은 셔츠·타이 순으로 줄인다.
- 두 색 모두 타이에만 적합하면 스트라이프/레지멘탈 타이의 바탕과 무늬색으로 사용할 수 있다.
- 남성 하의에는 레드·퍼플 등 비일상적인 색을 적용하지 않는다.

## 소품과 팔레트

착장에 적용하지 못한 색은 먼저 기존 내 옷장 아이템의 TPO·소재·색상 적합성을 검사한다. 실제 보유 아이템이 맞을 때만 소품 제안을 보여주고, 없으면 별도 문구 없이 팔레트만 유지한다.
