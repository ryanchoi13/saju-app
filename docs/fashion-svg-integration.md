# 달하 확정 도안과 자동 추천 연결 · 2026-09-16

현재 승인 SVG 추천 경로의 최종 기준은 [달하 코디 기준 v1.0](dalha-outfit-policy-v1.md)이다.
이 문서는 초기 연결 단계의 기록이며, 이후 검정 데님 허용·넥타이 무늬 판단 등은 최종 기준을 따른다.

## 구현 범위

기준 커밋 `f6fa139bc27d5a5551b588fb8c4bfbbdefea0153`에서 분리한
`codex/fashion-svg-integration` 작업이다. 이전 작업 공간의 미완료 변경은
수정하지 않았다. 운영 배포 및 전체 배색의 미적 승인을 뜻하지 않는다.

기존 `templates_for` / `weather_templates_for` / `classify_weather`의 완성 착장
선택 경로를 재사용한다. `svg_recommendation.py`가 기존 명리 A/B를 받아
확정 49종으로 착장을 정규화한 다음 색을 적용한다. 예전 화보 우선 반환
경로는 이 신규 응답에 적용하지 않는다. `main.py`의 실제 운세 응답과
`index.html`의 코디 버튼·추천 1/2 화면까지 연결했다.

- 승인 키트 7.3.1의 네 도안 소스는 그대로 복사했다. SHA256은
  `fashion-svg-art-provenance.json`에 기록했다. 도안 변경은 없다.
- 기존 템플릿의 미지원 아이템은 색 적용 전에 확정 도안 후보로 바꾸며,
  `selection_changes`에 원래 명칭·선택 명칭을 기록한다. 설명과 그림에는
  실제 선택한 명칭만 사용한다. 모르는 명칭은 조용히 대체하지 않고 오류 처리한다.
- 여성도 하의 안정색 제한을 적용하고 데님은 청색 계열을 사용한다.
- 수트는 한 색, 타이와 수트는 색/명도 분리, 정장 셔츠는 넣어 입기,
  니트·티셔츠는 기본 꺼내 입기, 원피스는 상하의 대체다.
- 50대 추천 1의 큰 면적에 강한 색을 제한한다. 추천 2는 같은 기본 제약
  안에서 다른 위치·원색 적용을 허용한다. 수치 점수는 구현용 초안이며
  시장 통계나 사용자 승인 가중치가 아니다.
- 큰 면적 사용이 가능한 위치부터 검토하며 외투 안에 가려진 상의는
  노출 면적을 낮춰 평가한다. 자연스럽지 않은 색은 팔레트에 남긴다.
- 원색/실제색/역할/톤 변경 이유/팔레트 안내 이유를 구분한다. 추가 오행색
  C는 만들지 않는다. 기본 의류색을 C로 기록하거나 오행을 재분류하지 않는다.
- 2~3색을 우선한다. 4색 산출은 `review_required`로 표시하며 이번 시각
  검토를 통과하기 전에는 미적 승인된 조합으로 취급하지 않는다.
- 아침저녁에도 더운 날, 일교차만 큰 이유로 외투를 챙기던 조건을 수정했다.
- 겨울 치마에 필요했던 타이츠 도안이 없어 해당 템플릿은 긴바지로 선택한다.
  아이템·소재의 실제 보온 성능을 검증했다는 뜻은 아니다.
- 코트와 수트 재킷이 겹치는 경우 원래 도안을 이중으로 합성하며 안쪽
  레이어는 바깥 외투의 앞 여밈으로만 노출한다.
- 한글 폰트는 기존 검토 키트의 NanumGothic을 오프라인 대체용으로 포함했다.
  원래 서비스의 Pretendard가 있으면 그 폰트를 우선한다.

## 확인 결과

- 관련 Python 테스트 31개 통과. 실제 Wada 120쌍 × 남녀 × 4계절 ×
  3 TPO × 2안 = 5,760착장의 구조·색 제한 검사 포함.
- 추가 연령/가상 날씨 300착장 검사, 승인된 핑크/차콜 남성 포멀 2안 회귀검사.
- 실제 `get_saju_pillars_and_analysis`를 실행해 기존 코어의 A/B가 보존되고
  모든 TPO의 두 안에 SVG 명세가 들어가는 것을 확인했다. 검사용 가상 인물이며
  사용자의 생시를 임의로 확정하지 않았다.
- 기존 코디 UI 회귀검사 통과. 실제 Chromium의 360/390/430/1280px에서
  가로 넘침 없음, 성별/TPO 필터, JSON 저장, 로컬 보관·불러오기 확인.
- 실제 `index.html`의 모달에서 두 SVG와 추천 1/2 전환 확인. 원격 로그인/API
  없이 로컬 시험 응답을 주입한 검사이며 운영 사이트를 조작하지 않았다.
- 실제 휴대폰 및 실제 당일 날씨를 넣은 전체 흐름은 미검증.

## 이번 검토 12벌

13–18번은 6조건 × 2안. `scripts/build_svg_review.py`는 성별·연령·TPO·계절,
가상 시간대별 기온, 시험 A/B만 지정한다. 최종 아이템색이나 배치 명세를
각 사례에 수동으로 넣지 않는다. 같은 실행 함수로 앱 응답과 검토 자료를 만든다.
입력색은 기존 24색 연구 풀이고 실제 오늘의 개인 명리 추천 결과가 아니다.

기존 통과 24벌과 이번 미검토 12벌의 기록은 별도다. 추천색을 바꾸거나
디자인을 다시 그려 이전 샘플을 재현한 것이 아니다. 16-2 파란 코트와
17-2 빨간 코트 등 강한 외투색은 사용자 판단이 필요한 사례로 남긴다.

## 재실행

```sh
python3 scripts/build_svg_review.py
node scripts/render_svg_review.mjs
python3 -m pytest backend/tests/test_fashion_v2_color_application.py backend/tests/test_fashion_v2_weather_outfit.py backend/tests/test_fashion_svg_integration.py -q
node scripts/test_fashion_v2_ui.cjs
node scripts/test_svg_browser.cjs
```

검토 PNG 생성은 sharp, 브라우저 검사는 Playwright/Chromium이 필요하다.
브라우저가 별도 설치된 환경은 `DALHA_CHROMIUM_EXECUTABLE`로 경로를 지정한다.
리뷰 산출물은 `review-output/svg-integration`에 생긴다.
