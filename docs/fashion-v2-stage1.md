# 패션 v2 1단계: 완성 코디 템플릿

## 범위

- 성별 2 × 계절 4 × TPO 3 × Daily/Trend 2 = 48개 완성 코디
- 개별 아이템을 임의 조합하지 않고, 검수된 한 세트를 통째로 선택
- 연령은 금지 조건이 아닌 소프트 가중치로만 사용
- 명리 A/B 색상 적용과 화면 연결은 다음 단계에서 진행
- 현재 상태는 `owner_review_pending`이며 운영 추천에는 아직 연결하지 않음

## 고정 규칙

- 남성 하의는 검정·남색·베이지·회색·청바지 계열의 현실적인 범위로 제한
- 남성 비즈니스 포멀은 수트 재킷과 바지의 색상·소재·수트 그룹이 반드시 일치
- 남성 비즈니스 포멀 신발은 옥스퍼드 또는 더비 구두
- 업무용 코디에는 반바지와 샌들을 사용하지 않음
- 여성 코디는 팬츠·스커트·원피스를 모두 포함
- 겨울 여성 스커트·원피스에는 타이츠 등 다리 보온 레이어 포함
- 액세서리는 완성 코디에 강제로 넣지 않고 별도 매칭이 있을 때만 노출

## 자동 검증

- 24개 범위와 48개 고유 템플릿 누락 여부
- 각 범위에 Daily와 Trend가 하나씩 존재하는지 여부
- 상의 또는 원피스와 신발이 빠지지 않았는지 여부
- 포멀 수트 일치, 신발, 계절성, 하의 색상, 여성 착장 형태 규칙
- 기존 백엔드 및 인터페이스 회귀 테스트

## 다음 단계

각 완성 코디를 먼저 선택한 뒤, 명리 A/B 색상을 넓은 면적·작은 포인트·팔레트 안내 중 가장 자연스러운 방식으로 적용한다. 두 색을 억지로 모두 사용하지 않는다.
