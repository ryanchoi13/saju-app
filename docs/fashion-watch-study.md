## 재사용 가능한 채색 기준

- 줄, 케이스/테두리, 문자판, 바늘/눈금을 별도 영역으로 관리한다.
- 같은 색을 줄과 테두리에 적용하는 것은 기본값의 선택이며 항상 묶일 필요는 없다.
- 추천 A/B를 어떤 부위에 적용했는지 부위 단위로 기록한다.
- 캐주얼·포멀 차이는 우선 줄의 재질 표현과 케이스 형태로 검토한다. 성별만으로 일률적인 색을 정하지 않는다.
- 가죽은 단순한 면, 금속 줄은 소수의 연결선으로 구분한다. 과한 광택·그림자는 추가하지 않는다.
- 금색 금속과 노란색 도장은 시각적으로 유사해도 같은 재질이나 오행이라고 자동 판단하지 않는다.
- 현재 승인된 18-2의 시계 배색은 사용자 지정 부위 색을 포함한 예외다. 이를 모든 자동 추천에 일반화하거나 명리 C 추가의 근거로 삼지 않는다.

현재 코디에 반영된 승인 시계는 그대로이며, 이 문서의 비율·연결부·용두 제안은 아직 도안에 적용하지 않았다.
